    30→## 1. Context & Current State
    31→
    32→### What Synapse Is Today
    33→
    34→Synapse is a WebSocket bridge between Claude and SideFX Houdini 21. It runs as a
    35→Python server inside Houdini's process, exposing the full `hou` module to Claude
    36→via JSON-over-WebSocket at `ws://localhost:9999`.
    37→
    38→**Protocol:** v4.0.0
    39→**Existing MCP Tools:**
    40→- `synapse_ping` — connectivity check, returns protocol version
    41→- `houdini_execute_python` — executes arbitrary Python in Houdini, returns `result` variable
    42→- `houdini_scene_info` — returns HIP file path, frame range, FPS
    43→- `houdini_capture_viewport` — screenshots the viewport
    44→
    45→**Safety Layers (implemented or in-progress):**
    46→- **Atomic scripts:** One mutation per `houdini_execute_python` call
    47→- **Idempotent guards:** `guards.py` module with `ensure_node()`, `ensure_connection()`,
    48→  `ensure_parm()`, `node_exists()`, etc. — auto-injected into exec namespace
    49→- **Transaction wrapper:** `hou.undos.group("synapse_operation")` with `hou.undos.performUndo()`
    50→  on exception — wraps all execute_python calls in the server handler
    51→
    52→**Tone System (designed, implementation in progress):**
    53→- Server-side message rewrites (errors → coaching language)
    54→- MCP tool description tone guidance
    55→- `TONE.md` voice guide for LLM context
    56→- Smart error enrichment (fuzzy node type matching, parameter discovery)
    57→
    58→**Planned MCP Tools (from roadmap, not yet built):**
    59→- `synapse_inspect_selection` — structured data on selected nodes
    60→- `synapse_inspect_scene` — hierarchical scene overview
    61→- `synapse_inspect_node` — deep single-node analysis
    62→
    63→**Known Houdini 21 Conventions:**
    64→- USD/Solaris nodes live at `/stage/`
    65→- USD light parameter names use encoded form: `xn__inputsintensity_i0a` (not `intensity`)
    66→- MaterialX shading via `mtlxstandard_surface` nodes
    67→- Karma renderer (CPU and XPU) for final output
    68→- Scene graph connections flow through merge nodes (e.g., `/stage/scene_merge`)
    69→
    70→**File System:**
    71→- Synapse source: `C:/Users/User/.synapse/`
    72→- Shared transfer dir: `C:/Users/User/.synapse/` (also used for render output)
    73→- Houdini projects: `D:/HOUDINI_PROJECTS_2025/`
    74→
    75→### What We're Building
    76→
    77→An **autonomous agent** using the Claude Agent SDK (Python) that:
    78→1. Receives high-level VFX goals from the artist
    79→2. Plans multi-step approaches using extended thinking
    80→3. Executes against live Houdini via WebSocket (Synapse)
    81→4. Verifies its own work via scene inspection
    82→5. Iterates until the result matches intent
    83→6. Communicates progress in encouraging, coaching language
    84→
    85→### Why the Agent SDK
    86→
    87→| Capability | MCP Bridge (current) | Agent SDK (new) |
    88→|------------|---------------------|-----------------|
    89→| Thinking depth | Standard | Extended thinking (Opus 4.6) |
    90→| Autonomy | Reactive (user drives each step) | Autonomous (agent drives loops) |
    91→| Tool chaining | LLM decides per-turn | Agent plans multi-step sequences |
    92→| Error recovery | Manual retry | Hooks auto-rollback + retry |
    93→| Verification | User checks result | Agent self-verifies |
    94→| Context mgmt | Manual | Compaction (infinite conversation) |
    95→| Parallelism | Sequential only | Subagents for concurrent work |
    96→| File access | None | Full filesystem (read specs, write logs) |

   186→## 4. Phase 0: WebSocket Client
   187→
   188→### `synapse_ws.py`
   189→
   190→This is the low-level async WebSocket client that talks to Synapse.
   191→It replaces the MCP protocol hop with a direct connection.
   192→
   193→```python
   194→"""
   195→synapse_ws.py — Async WebSocket client for Synapse/Houdini bridge.
   196→
   197→Connects directly to the Synapse server running inside Houdini at ws://localhost:9999.
   198→All calls are async and return parsed JSON responses.
   199→
   200→This module is the ONLY place that touches the WebSocket connection.
   201→All other modules call functions from here.
   202→"""
   203→
   204→import asyncio
   205→import json
   206→import logging
   207→from typing import Any, Optional
   208→from contextlib import asynccontextmanager
   209→
   210→logger = logging.getLogger("synapse.ws")
   211→
   212→# --- Configuration ---
   213→SYNAPSE_HOST = "localhost"
   214→SYNAPSE_PORT = 9999
   215→SYNAPSE_URI = f"ws://{SYNAPSE_HOST}:{SYNAPSE_PORT}"
   216→CONNECT_TIMEOUT = 10.0
   217→CALL_TIMEOUT = 120.0  # Houdini operations can take time (renders, cooks)
   218→RENDER_TIMEOUT = 600.0  # 10 min for render calls
   219→
   220→
   221→class SynapseConnectionError(Exception):
   222→    """Raised when we can't reach Synapse."""
   223→    pass
   224→
   225→
   226→class SynapseExecutionError(Exception):
   227→    """Raised when Houdini-side execution fails."""
   228→    def __init__(self, message: str, partial_result: Any = None):
   229→        super().__init__(message)
   230→        self.partial_result = partial_result
   231→
   232→
   233→class SynapseClient:
   234→    """
   235→    Async WebSocket client for Synapse.
   236→
   237→    Usage:
   238→        client = SynapseClient()
   239→        await client.connect()
   240→        result = await client.execute_python("result = hou.node('/stage').children()")
   241→        await client.disconnect()
   242→
   243→    Or as context manager:
   244→        async with SynapseClient() as client:
   245→            result = await client.ping()
   246→    """
   247→
   248→    def __init__(self, uri: str = SYNAPSE_URI):
   249→        self.uri = uri
   250→        self._ws = None
   251→        self._connected = False
   252→        self._lock = asyncio.Lock()  # Serialize WebSocket calls
   253→
   254→    async def connect(self) -> bool:
   255→        """Establish WebSocket connection to Synapse."""
   256→        try:
   257→            import websockets
   258→            self._ws = await asyncio.wait_for(
   259→                websockets.connect(self.uri),
   260→                timeout=CONNECT_TIMEOUT
   261→            )
   262→            self._connected = True
   263→            logger.info(f"Connected to Synapse at {self.uri}")
   264→            return True
   265→        except asyncio.TimeoutError:
   266→            raise SynapseConnectionError(
   267→                f"Couldn't reach Synapse at {self.uri} — is Houdini running with the Synapse server active?"
   268→            )
   269→        except Exception as e:
   270→            raise SynapseConnectionError(
   271→                f"Connection to Synapse failed: {e}. Check that Houdini is running and Synapse is loaded."
   272→            )
   273→
   274→    async def disconnect(self):
   275→        """Close the WebSocket connection."""
   276→        if self._ws:
   277→            await self._ws.close()
   278→            self._connected = False
   279→            logger.info("Disconnected from Synapse")
   280→
   281→    async def __aenter__(self):
   282→        await self.connect()
   283→        return self
   284→
   285→    async def __aexit__(self, exc_type, exc_val, exc_tb):
   286→        await self.disconnect()
   287→
   288→    async def _send_and_receive(self, message: dict, timeout: float = CALL_TIMEOUT) -> dict:
   289→        """
   290→        Send a JSON message and wait for the response.
   291→        Serialized via lock to prevent interleaved WebSocket frames.
   292→        """
   293→        if not self._connected or not self._ws:
   294→            raise SynapseConnectionError("Not connected to Synapse. Call connect() first.")
   295→
   296→        async with self._lock:
   297→            try:
   298→                await self._ws.send(json.dumps(message))
   299→                raw = await asyncio.wait_for(self._ws.recv(), timeout=timeout)
   300→                return json.loads(raw)
   301→            except asyncio.TimeoutError:
   302→                raise SynapseExecutionError(
   303→                    f"Synapse didn't respond within {timeout}s — the operation might still be running in Houdini. "
   304→                    f"Check the Houdini viewport."
   305→                )
   306→            except Exception as e:
   307→                raise SynapseExecutionError(f"Communication error: {e}")
   308→
   309→    # --- High-Level API ---
   310→
   311→    async def ping(self) -> dict:
   312→        """Check Synapse connectivity. Returns protocol version info."""
   313→        response = await self._send_and_receive(
   314→            {"tool": "synapse_ping"},
   315→            timeout=5.0
   316→        )
   317→        return response
   318→
   319→    async def scene_info(self) -> dict:
   320→        """Get current scene metadata (HIP path, frame range, FPS)."""
   321→        response = await self._send_and_receive(
   322→            {"tool": "houdini_scene_info"}
   323→        )
   324→        return response
   325→
   326→    async def execute_python(self, code: str, timeout: float = CALL_TIMEOUT) -> Any:
   327→        """
   328→        Execute Python code inside Houdini. Returns the value of the `result` variable.
   329→
   330→        The Synapse server handler wraps execution in hou.undos.group() and auto-injects
   331→        guard functions (ensure_node, ensure_connection, etc.) into the namespace.
   332→
   333→        Args:
   334→            code: Python source code to execute. Set a `result` variable for return value.
   335→            timeout: Max seconds to wait (default 120, use RENDER_TIMEOUT for renders).
   336→
   337→        Returns:
   338→            The value of `result` from the executed code, or None.
   339→
   340→        Raises:
   341→            SynapseExecutionError: If the code throws an exception (scene is auto-rolled-back).
   342→        """
   343→        response = await self._send_and_receive(
   344→            {"tool": "houdini_execute_python", "code": code},
   345→            timeout=timeout
   346→        )
   347→
   348→        # Handle Synapse response format
   349→        if isinstance(response, dict):
   350→            if response.get("error"):
   351→                raise SynapseExecutionError(
   352→                    response.get("error", "Unknown execution error"),
   353→                    partial_result=response.get("result")
   354→                )
   355→            return response.get("result")
   356→        return response
   357→
   358→    async def capture_viewport(self, output_path: Optional[str] = None) -> str:
   359→        """
   360→        Capture a viewport screenshot.
   361→
   362→        Args:
   363→            output_path: Where to save. Defaults to .synapse/viewport_capture.png
   364→
   365→        Returns:
   366→            Path to the saved screenshot.
   367→        """
   368→        msg = {"tool": "houdini_capture_viewport"}
   369→        if output_path:
   370→            msg["output_path"] = output_path
   371→        response = await self._send_and_receive(msg, timeout=30.0)
   372→        return response
   373→
   374→    # --- Convenience Methods ---
   375→
   376→    async def execute_read(self, code: str) -> Any:
   377→        """Execute read-only code (no mutations). Same as execute_python but semantic."""
   378→        return await self.execute_python(code)
   379→
   380→    async def execute_render(self, code: str) -> Any:
   381→        """Execute render-triggering code with extended timeout."""
   382→        return await self.execute_python(code, timeout=RENDER_TIMEOUT)
   383→```

   395→## 5. Phase 1: Custom Tools
   396→
   397→### `synapse_tools.py`
   398→
   399→Custom tools registered with `ClaudeSDKClient`. These are what Opus 4.6 calls
   400→during the agent loop. Each tool is an in-process MCP server — no separate process needed.
   401→
   402→**Design Principles:**
   403→- Each tool does ONE thing clearly
   404→- Read tools are separate from mutation tools
   405→- Every mutation tool returns verification data
   406→- Tool docstrings are written in coaching tone (these become tool descriptions in the LLM context)
   407→
   408→```python
   409→"""
   410→synapse_tools.py — Custom tools for the Synapse Agent.
   411→
   412→These tools are registered with ClaudeSDKClient and become available
   413→to Opus 4.6 during the agent loop. They wrap WebSocket calls to Synapse
   414→running inside Houdini 21.
   415→
   416→Tool docstrings are important — they appear in the LLM context and shape
   417→how the agent describes operations to the artist.
   418→"""
   419→
   420→import json
   421→import logging
   422→from typing import Optional
   423→from synapse_ws import SynapseClient, SynapseExecutionError
   424→
   425→logger = logging.getLogger("synapse.tools")
   426→
   427→# Global client instance — initialized in synapse_agent.py
   428→_client: Optional[SynapseClient] = None
   429→
   430→
   431→def set_client(client: SynapseClient):
   432→    """Set the shared WebSocket client. Called once during agent init."""
   433→    global _client
   434→    _client = client
   435→
   436→
   437→def get_client() -> SynapseClient:
   438→    if _client is None:
   439→        raise RuntimeError("Synapse client not initialized. Call set_client() first.")
   440→    return _client

   447→async def synapse_ping() -> str:
   448→    """
   449→    Check if Synapse and Houdini are reachable.
   450→    Call this first to verify the connection before doing any scene work.
   451→    Returns protocol version and connection status.
   452→    """
   453→    client = get_client()
   454→    try:
   455→        result = await client.ping()
   456→        return json.dumps({"status": "connected", "details": result})
   457→    except Exception as e:
   458→        return json.dumps({
   459→            "status": "disconnected",
   460→            "message": f"Can't reach Synapse — {e}. Is Houdini running?"
   461→        })

   463→
   464→async def synapse_scene_info() -> str:
   465→    """
   466→    Get an overview of the current Houdini scene.
   467→    Returns the HIP file path, current frame, frame range, and FPS.
   468→    Good for orientation — call this early to understand what we're working with.
   469→    """
   470→    client = get_client()
   471→    result = await client.scene_info()
   472→    return json.dumps(result, indent=2)
   473→
   474→
   475→# ─────────────────────────────────────────────────────────────
   476→# SCENE INTROSPECTION (READ-ONLY — safe to call anytime)
   477→# ─────────────────────────────────────────────────────────────
   478→
   479→async def synapse_inspect_scene(
   480→    root_path: str = "/",
   481→    max_depth: int = 3,
   482→    context_filter: str = ""
   483→) -> str:
   484→    """
   485→    Walk the Houdini scene graph and return a structured overview.
   486→    Shows network topology, node counts, flagged nodes, errors, and warnings.
   487→    This is a quick orientation tool — not a full parameter dump.
   488→
   489→    Use this when you need to understand what's in the scene before making changes.
   490→
   491→    Args:
   492→        root_path: Where to start walking (default "/" for everything).
   493→        max_depth: How deep to recurse (default 3).
   494→        context_filter: Limit to a specific context like "Lop" or "Sop" (empty = all).
   495→    """
   496→    client = get_client()
   497→    code = f'''
   498→import hou
   499→import json
   500→from collections import defaultdict
   501→
   502→def inspect_network(parent, depth=0, max_depth={max_depth}, context_filter="{context_filter}"):
   503→    if depth > max_depth:
   504→        return None
   505→
   506→    children = parent.children()
   507→    if not children:
   508→        return None
   509→
   510→    network = {{
   511→        "path": parent.path(),
   512→        "node_count": len(children),
   513→        "types": defaultdict(int),
   514→        "flagged": [],
   515→        "issues": [],
   516→        "children": []
   517→    }}
   518→
   519→    for node in children:
   520→        cat = node.type().category().name()
   521→        if context_filter and cat.lower() != context_filter.lower():
   522→            continue
   523→
   524→        network["types"][node.type().name()] += 1
   525→
   526→        # Check flags
   527→        flags = []
   528→        try:
   529→            if node.isDisplayFlagSet(): flags.append("display")
   530→        except: pass
   531→        try:
   532→            if node.isRenderFlagSet(): flags.append("render")
   533→        except: pass
   534→        try:
   535→            if node.isBypassed(): flags.append("bypass")
   536→        except: pass
   537→        if flags:
   538→            network["flagged"].append({{"path": node.path(), "flags": flags}})
   539→
   540→        # Check issues
   541→        errors = node.errors()
   542→        warnings = node.warnings()
   543→        if errors:
   544→            network["issues"].append({{"path": node.path(), "errors": errors}})
   545→        if warnings:
   546→            network["issues"].append({{"path": node.path(), "warnings": warnings}})
   547→
   548→        # Recurse
   549→        child_network = inspect_network(node, depth + 1, max_depth, context_filter)
   550→        if child_network:
   551→            network["children"].append(child_network)
   552→
   553→    network["types"] = dict(network["types"])
   554→    return network
   555→
   556→root = hou.node("{root_path}")
   557→if root:
   558→    result = json.dumps(inspect_network(root), indent=2)
   559→else:
   560→    result = json.dumps({{"error": "Root path not found", "path": "{root_path}"}})
   561→'''
   562→    return await client.execute_read(code)

   564→
   565→async def synapse_inspect_selection(depth: int = 1) -> str:
   566→    """
   567→    Analyze all currently selected nodes in Houdini.
   568→    Returns detailed info: paths, types, modified parameters, connections,
   569→    geometry attributes (for SOPs), errors, and warnings.
   570→
   571→    Use this when the artist says "look at what I have selected" or when you
   572→    need to understand the current working context.
   573→
   574→    Args:
   575→        depth: How many levels of input nodes to also inspect (default 1).
   576→    """
   577→    client = get_client()
   578→    code = f'''
   579→import hou
   580→import json
   581→
   582→def inspect_node(node, depth=0, max_depth={depth}):
   583→    data = {{
   584→        "path": node.path(),
   585→        "type": node.type().name(),
   586→        "category": node.type().category().name(),
   587→        "modified_parms": {{}},
   588→        "inputs": [],
   589→        "outputs": [],
   590→        "errors": node.errors(),
   591→        "warnings": node.warnings()
   592→    }}
   593→
   594→    # Modified parameters only (skip defaults)
   595→    for p in node.parms():
   596→        try:
   597→            if not p.isAtDefault():
   598→                val = p.eval()
   599→                # Handle non-serializable types
   600→                if isinstance(val, (hou.Vector3, hou.Vector4)):
   601→                    val = list(val)
   602→                elif isinstance(val, hou.Matrix4):
   603→                    val = str(val)
   604→                data["modified_parms"][p.name()] = val
   605→        except:
   606→            pass
   607→
   608→    # Connections
   609→    for i, inp in enumerate(node.inputs()):
   610→        if inp:
   611→            data["inputs"].append({{"index": i, "path": inp.path(), "type": inp.type().name()}})
   612→    for out in node.outputs():
   613→        data["outputs"].append({{"path": out.path(), "type": out.type().name()}})
   614→
   615→    # Geometry attributes (SOP context)
   616→    if node.type().category().name() == "Sop":
   617→        try:
   618→            geo = node.geometry()
   619→            if geo:
   620→                data["geometry"] = {{
   621→                    "points": geo.intrinsicValue("pointcount"),
   622→                    "prims": geo.intrinsicValue("primitivecount"),
   623→                    "attribs": {{}}
   624→                }}
   625→                for context, method in [("point", geo.pointAttribs),
   626→                                         ("prim", geo.primAttribs),
   627→                                         ("vertex", geo.vertexAttribs),
   628→                                         ("detail", geo.globalAttribs)]:
   629→                    data["geometry"]["attribs"][context] = [
   630→                        {{"name": a.name(), "type": str(a.dataType()), "size": a.size()}}
   631→                        for a in method()
   632→                    ]
   633→        except:
   634→            pass
   635→
   636→    # Recurse into inputs
   637→    if depth < max_depth:
   638→        data["input_nodes"] = []
   639→        for inp in node.inputs():
   640→            if inp:
   641→                data["input_nodes"].append(inspect_node(inp, depth + 1, max_depth))
   642→
   643→    return data
   644→
   645→selected = hou.selectedNodes()
   646→if not selected:
   647→    result = json.dumps({{"message": "No nodes selected — select some nodes in Houdini and try again", "count": 0}})
   648→else:
   649→    nodes_data = [inspect_node(n) for n in selected]
   650→    result = json.dumps({{
   651→        "count": len(nodes_data),
   652→        "nodes": nodes_data
   653→    }}, indent=2)
   654→'''
   655→    return await client.execute_read(code)

   657→
   658→async def synapse_inspect_node(
   659→    node_path: str,
   660→    include_code: bool = True,
   661→    include_geometry: bool = True,
   662→    include_expressions: bool = True
   663→) -> str:
   664→    """
   665→    Deep inspection of a single node — gets EVERYTHING.
   666→    All parameters (including defaults), expressions, code content for wrangles,
   667→    geometry attributes with value ranges, HDA info, and cook dependencies.
   668→
   669→    Use this when you need to fully understand one specific node before modifying it.
   670→
   671→    Args:
   672→        node_path: Absolute path to the node (e.g., "/stage/key_light").
   673→        include_code: Include VEX/Python code from wrangle nodes (default true).
   674→        include_geometry: Include geometry attribute summary (default true).
   675→        include_expressions: Include parameter expressions and references (default true).
   676→    """
   677→    client = get_client()
   678→    code = f'''
   679→import hou
   680→import json
   681→
   682→node = hou.node("{node_path}")
   683→if not node:
   684→    result = json.dumps({{"error": "Node not found", "path": "{node_path}",
   685→        "hint": "Check the path — try synapse_inspect_scene to see what's available"}})
   686→else:
   687→    data = {{
   688→        "path": node.path(),
   689→        "type": node.type().name(),
   690→        "category": node.type().category().name(),
   691→        "label": node.type().description(),
   692→        "parameters": {{}},
   693→        "inputs": [],
   694→        "outputs": [],
   695→        "flags": {{}},
   696→        "errors": node.errors(),
   697→        "warnings": node.warnings(),
   698→        "cook_time": None
   699→    }}
   700→
   701→    # All parameters grouped by folder
   702→    for parm_tuple in node.parmTuples():
   703→        folder = parm_tuple.containingFolders()
   704→        folder_key = " > ".join(folder) if folder else "Main"
   705→        if folder_key not in data["parameters"]:
   706→            data["parameters"][folder_key] = {{}}
   707→        for p in parm_tuple:
   708→            parm_data = {{
   709→                "value": None,
   710→                "is_default": p.isAtDefault(),
   711→            }}
   712→            try:
   713→                parm_data["value"] = p.eval()
   714→                if isinstance(parm_data["value"], (hou.Vector3, hou.Vector4)):
   715→                    parm_data["value"] = list(parm_data["value"])
   716→            except:
   717→                parm_data["value"] = "<unevaluable>"
   718→
   719→            if {str(include_expressions).lower()}:
   720→                try:
   721→                    expr = p.expression()
   722→                    if expr:
   723→                        parm_data["expression"] = expr
   724→                        parm_data["expression_language"] = str(p.expressionLanguage())
   725→                except:
   726→                    pass
   727→                # Channel references
   728→                try:
   729→                    ref = p.getReferencedParm()
   730→                    if ref and ref != p:
   731→                        parm_data["references"] = ref.path()
   732→                except:
   733→                    pass
   734→
   735→            data["parameters"][folder_key][p.name()] = parm_data
   736→
   737→    # Connections
   738→    for i, inp in enumerate(node.inputs()):
   739→        if inp:
   740→            data["inputs"].append({{"index": i, "path": inp.path()}})
   741→    for out in node.outputs():
   742→        data["outputs"].append({{"path": out.path()}})
   743→
   744→    # Flags
   745→    try: data["flags"]["display"] = node.isDisplayFlagSet()
   746→    except: pass
   747→    try: data["flags"]["render"] = node.isRenderFlagSet()
   748→    except: pass
   749→    try: data["flags"]["bypass"] = node.isBypassed()
   750→    except: pass
   751→
   752→    # Code content (wrangles, python nodes)
   753→    if {str(include_code).lower()}:
   754→        for parm_name in ["snippet", "python", "code", "script", "vexcode"]:
   755→            parm = node.parm(parm_name)
   756→            if parm:
   757→                try:
   758→                    data["code_content"] = {{
   759→                        "parameter": parm_name,
   760→                        "code": parm.eval()
   761→                    }}
   762→                    break
   763→                except:
   764→                    pass
   765→
   766→    # HDA info
   767→    definition = node.type().definition()
   768→    if definition:
   769→        data["hda"] = {{
   770→            "library_path": definition.libraryFilePath(),
   771→            "embedded": definition.isEmbedded(),
   772→            "sections": list(definition.sections().keys())[:10]
   773→        }}
   774→
   775→    # Geometry
   776→    if {str(include_geometry).lower()} and node.type().category().name() == "Sop":
   777→        try:
   778→            geo = node.geometry()
   779→            if geo:
   780→                data["geometry"] = {{
   781→                    "points": geo.intrinsicValue("pointcount"),
   782→                    "prims": geo.intrinsicValue("primitivecount"),
   783→                    "bounds": list(geo.boundingBox().minvec()) + list(geo.boundingBox().maxvec()),
   784→                    "attribs": {{}}
   785→                }}
   786→                for ctx_name, method in [("point", geo.pointAttribs),
   787→                                          ("prim", geo.primAttribs),
   788→                                          ("vertex", geo.vertexAttribs),
   789→                                          ("detail", geo.globalAttribs)]:
   790→                    attribs = []
   791→                    for a in method():
   792→                        attr_data = {{"name": a.name(), "type": str(a.dataType()), "size": a.size()}}
   793→                        # Sample first few values for numeric types
   794→                        try:
   795→                            if a.dataType() in (hou.attribData.Float, hou.attribData.Int):
   796→                                if ctx_name == "point" and geo.intrinsicValue("pointcount") > 0:
   797→                                    samples = [geo.point(i).attribValue(a) for i in range(min(3, geo.intrinsicValue("pointcount")))]
   798→                                    attr_data["samples"] = samples
   799→                        except:
   800→                            pass
   801→                        attribs.append(attr_data)
   802→                    data["geometry"]["attribs"][ctx_name] = attribs
   803→        except:
   804→            pass
   805→
   806→    # Cook time
   807→    try:
   808→        profile = node.cookProfile()
   809→        if profile:
   810→            data["cook_time"] = profile.cookTime()
   811→    except:
   812→        pass
   813→
   814→    result = json.dumps(data, indent=2, default=str)
   815→'''
   816→    return await client.execute_read(code)
   817→
   818→
   819→# ─────────────────────────────────────────────────────────────
   820→# EXECUTION (MUTATIONS — these change the scene)
   821→# ─────────────────────────────────────────────────────────────
   822→
   823→async def synapse_execute(
   824→    code: str,
   825→    description: str = "",
   826→    verify_paths: str = ""
   827→) -> str:
   828→    """
   829→    Execute Python code in Houdini. Use this to create nodes, set parameters,
   830→    connect wires, and modify the scene.
   831→
   832→    SAFETY: The Synapse server automatically wraps all execution in an undo group.
   833→    If anything fails, all changes are rolled back — the scene won't be left in a
   834→    broken state.
   835→
   836→    IMPORTANT CONVENTIONS:
   837→    - One mutation per call. Don't create + connect + set parms in one script.
   838→    - Use guard functions for idempotency: ensure_node(), ensure_connection(), ensure_parm()
   839→    - These guards are auto-available in the namespace (no import needed).
   840→    - Set a `result` variable to return data to the agent.
   841→
   842→    Args:
   843→        code: Python code to execute. Has access to `hou` module and guard functions.
   844→        description: Human-readable description of what this operation does.
   845→        verify_paths: Comma-separated node paths to verify after execution.
   846→
   847→    When things go well, you'll get the result back. When they don't, you'll get a
   848→    clear error explaining what happened and the scene will be rolled back to its
   849→    previous state.
   850→    """
   851→    client = get_client()
   852→    logger.info(f"Executing: {description or 'unlabeled operation'}")
   853→
   854→    try:
   855→        result = await client.execute_python(code)
   856→
   857→        # If verify_paths provided, check they exist
   858→        if verify_paths:
   859→            paths = [p.strip() for p in verify_paths.split(",") if p.strip()]
   860→            verify_code = f"""
   861→import hou
   862→import json
   863→checks = {{}}
   864→for path in {paths}:
   865→    node = hou.node(path)
   866→    checks[path] = {{
   867→        "exists": node is not None,
   868→        "type": node.type().name() if node else None,
   869→        "errors": node.errors() if node else None
   870→    }}
   871→result = json.dumps(checks, indent=2)
   872→"""
   873→            verification = await client.execute_read(verify_code)
   874→            return json.dumps({
   875→                "executed": True,
   876→                "result": result,
   877→                "verification": json.loads(verification) if isinstance(verification, str) else verification,
   878→                "description": description
   879→            }, indent=2, default=str)
   880→
   881→        return json.dumps({
   882→            "executed": True,
   883→            "result": result,
   884→            "description": description
   885→        }, indent=2, default=str)
   886→
   887→    except SynapseExecutionError as e:
   888→        return json.dumps({
   889→            "executed": False,
   890→            "error": str(e),
   891→            "rolled_back": True,
   892→            "description": description,
   893→            "hint": "The scene was rolled back to its previous state. Check the code and try again."
   894→        }, indent=2)
   895→

   973→## 6. Phase 2: Safety Hooks
   974→
   975→### `synapse_hooks.py`
   976→
   977→Hooks fire on agent lifecycle events. These implement the three safety layers
   978→at the agent level (complementing the server-side undo-group).
   979→
   980→```python
   981→"""
   982→synapse_hooks.py — Safety and verification hooks for the Synapse Agent.
   983→
   984→These hooks fire automatically during the agent loop:
   985→- pre_tool_call: Validates tool calls before execution
   986→- post_tool_call: Auto-verifies mutations after execution
   987→- on_error: Enriches error messages with coaching tone and suggestions
   988→
   989→The hooks complement the server-side safety (undo groups, guards.py) with
   990→agent-side intelligence.
   991→"""
   992→
   993→import json
   994→import logging
   995→import re
   996→from typing import Any, Optional
   997→from synapse_tone import enrich_error_message, format_success_message
   998→
   999→logger = logging.getLogger("synapse.hooks")
  1000→
  1001→
  1002→# ─────────────────────────────────────────────────────────────
  1003→# PRE-EXECUTION VALIDATION
  1004→# ─────────────────────────────────────────────────────────────
  1005→
  1006→def validate_atomic_convention(code: str) -> tuple[bool, str]:
  1007→    """
  1008→    Check if a code block follows the atomic convention (one mutation per call).
  1009→
  1010→    Heuristic: count mutation keywords. If >1 distinct mutation type, flag it.
  1011→    This is advisory — doesn't block execution, but warns the agent.
  1012→    """
  1013→    mutation_patterns = [
  1014→        (r'\.createNode\(', 'node creation'),
  1015→        (r'\.setInput\(', 'connection'),
  1016→        (r'\.set\(', 'parameter set'),  # parm.set()
  1017→        (r'\.destroy\(', 'node deletion'),
  1018→        (r'\.move\(', 'node move'),
  1019→    ]
  1020→
  1021→    found_mutations = set()
  1022→    for pattern, label in mutation_patterns:
  1023→        if re.search(pattern, code):
  1024→            found_mutations.add(label)
  1025→
  1026→    if len(found_mutations) > 1:
  1027→        return False, (
  1028→            f"This script has multiple mutation types ({', '.join(found_mutations)}). "
  1029→            f"For safety, split into separate calls — one mutation per execute. "
  1030→            f"Read operations can stay combined."
  1031→        )
  1032→
  1033→    return True, "Looks good — single mutation type."
  1034→
  1035→
  1036→def validate_guard_usage(code: str) -> tuple[bool, str]:
  1037→    """
  1038→    Check if mutations use guard functions for idempotency.
  1039→    Advisory — encourages but doesn't block.
  1040→    """
  1041→    has_raw_create = bool(re.search(r'\.createNode\(', code))
  1042→    has_guard_create = bool(re.search(r'ensure_node\(', code))
  1043→
  1044→    has_raw_connect = bool(re.search(r'\.setInput\(', code))
  1045→    has_guard_connect = bool(re.search(r'ensure_connection\(', code))
  1046→
  1047→    warnings = []
  1048→    if has_raw_create and not has_guard_create:
  1049→        warnings.append(
  1050→            "Using raw createNode() — consider ensure_node() to prevent duplicates on retry."
  1051→        )
  1052→    if has_raw_connect and not has_guard_connect:
  1053→        warnings.append(
  1054→            "Using raw setInput() — consider ensure_connection() to prevent duplicate wiring."
  1055→        )
  1056→
  1057→    if warnings:
  1058→        return False, " ".join(warnings)
  1059→    return True, "Guard functions used appropriately."
  1060→
  1061→
  1062→# ─────────────────────────────────────────────────────────────
  1063→# HOOK FUNCTIONS (for ClaudeSDKClient registration)
  1064→# ─────────────────────────────────────────────────────────────
  1065→
  1066→async def pre_tool_call_hook(tool_name: str, tool_input: dict) -> Optional[str]:
  1067→    """
  1068→    Called before each tool invocation. Returns None to proceed, or a string
  1069→    message that gets injected into the agent's context as a warning.
  1070→    """
  1071→    if tool_name == "synapse_execute":
  1072→        code = tool_input.get("code", "")
  1073→
  1074→        # Check atomic convention
  1075→        is_atomic, atomic_msg = validate_atomic_convention(code)
  1076→        if not is_atomic:
  1077→            logger.warning(f"Atomic convention violation: {atomic_msg}")
  1078→            return f"⚠️ Safety note: {atomic_msg}"
  1079→
  1080→        # Check guard usage
  1081→        uses_guards, guard_msg = validate_guard_usage(code)
  1082→        if not uses_guards:
  1083→            logger.info(f"Guard suggestion: {guard_msg}")
  1084→            # Don't block, just log — guards are a best practice, not a hard rule
  1085→
  1086→    return None  # Proceed normally
  1087→
  1088→
  1089→async def post_tool_call_hook(tool_name: str, tool_input: dict, tool_result: Any) -> Optional[str]:
  1090→    """
  1091→    Called after each tool invocation. Can inject follow-up context.
  1092→    Used here to auto-verify mutations.
  1093→    """
  1094→    if tool_name == "synapse_execute":
  1095→        try:
  1096→            result_data = json.loads(tool_result) if isinstance(tool_result, str) else tool_result
  1097→            if result_data.get("executed"):
  1098→                return format_success_message(
  1099→                    tool_input.get("description", "operation"),
  1100→                    result_data
  1101→                )
  1102→            elif result_data.get("error"):
  1103→                return enrich_error_message(
  1104→                    result_data.get("error", ""),
  1105→                    tool_input.get("code", "")
  1106→                )
  1107→        except (json.JSONDecodeError, AttributeError):
  1108→            pass
  1109→
  1110→    return None
  1111→
  1112→
  1113→async def on_error_hook(error: Exception) -> Optional[str]:
  1114→    """
  1115→    Called when an unhandled error occurs. Enriches error messages
  1116→    with coaching tone and recovery suggestions.
  1117→    """
  1118→    error_msg = str(error)
  1119→    return enrich_error_message(error_msg, "")
  1120→```
  1121→
  1122→### `synapse_tone.py`
  1123→
  1124→The coaching language formatter used by hooks and tools.
  1125→
  1126→```python
  1127→"""
  1128→synapse_tone.py — Coaching language for Synapse communications.
  1129→
  1130→Every message the artist sees should pass the validation test:
  1131→"Would this message make an artist having a rough day want to keep going
  1132→ or close the application?"
  1133→
  1134→Principles:
  1135→1. Never blame — "I couldn't find" not "you gave wrong path"
  1136→2. Plain language first — technical details can follow
  1137→3. Always offer a next step — every error suggests what to try
  1138→4. "We/I" framing — collaborative, not diagnostic
  1139→5. Forward momentum — success messages imply "what's next"
  1140→"""
  1141→
  1142→import re
  1143→from typing import Any
  1144→
  1145→
  1146→def enrich_error_message(error: str, code: str) -> str:
  1147→    """
  1148→    Transform a raw error into coaching language with suggestions.
  1149→    """
  1150→    enriched = error
  1151→
  1152→    # Node not found
  1153→    if "not found" in error.lower() or "none" in error.lower():
  1154→        path_match = re.search(r"['\"]?(/[a-zA-Z0-9_/]+)['\"]?", error)
  1155→        if path_match:
  1156→            path = path_match.group(1)
  1157→            enriched = (
  1158→                f"Couldn't find a node at `{path}` — it might have been renamed or "
  1159→                f"might not exist yet. I can search the scene to find the right path."
  1160→            )
  1161→        else:
  1162→            enriched = (
  1163→                f"Something I expected to find wasn't there. Let me inspect the "
  1164→                f"scene to get re-oriented."
  1165→            )
  1166→
  1167→    # Parameter errors
  1168→    elif "parameter" in error.lower() or "parm" in error.lower():
  1169→        enriched = (
  1170→            f"Hit a parameter issue: {error}. H21 USD nodes use encoded parameter names "
  1171→            f"(like `xn__inputsintensity_i0a` instead of `intensity`). "
  1172→            f"I can inspect the node to find the exact parameter names."
  1173→        )
  1174→
  1175→    # Permission / path errors
  1176→    elif "permission" in error.lower() or "writable" in error.lower():
  1177→        enriched = (
  1178→            f"Couldn't write to the output path — might be a permissions issue. "
  1179→            f"I'll try using C:/Users/User/.synapse/ instead."
  1180→        )
  1181→
  1182→    # Type errors
  1183→    elif "NoneType" in error or "AttributeError" in error:
  1184→        enriched = (
  1185→            f"Something I expected to exist wasn't there yet — likely a node or "
  1186→            f"parameter that wasn't created in a previous step. Let me check "
  1187→            f"the scene state and try a different approach."
  1188→        )
  1189→
  1190→    # Generic fallback
  1191→    elif not any(phrase in enriched for phrase in ["I can", "I'll", "Let me"]):
  1192→        enriched = f"{error}. Let me take a different approach."
  1193→
  1194→    return f"🔧 {enriched}"
  1195→
  1196→
  1197→def format_success_message(description: str, result_data: Any) -> str:
  1198→    """
  1199→    Format a success result with forward momentum.
  1200→    """
  1201→    result = result_data.get("result", "")
  1202→    verification = result_data.get("verification", {})
  1203→
  1204→    parts = [f"✓ {description} — done."]
  1205→
  1206→    if verification:
  1207→        all_ok = all(v.get("exists", False) for v in verification.values())
  1208→        error_count = sum(1 for v in verification.values() if v.get("errors"))
  1209→        if all_ok and error_count == 0:
  1210→            parts.append("Verified — everything checks out.")
  1211→        elif not all_ok:
  1212→            missing = [k for k, v in verification.items() if not v.get("exists")]
  1213→            parts.append(f"Heads up: {', '.join(missing)} didn't make it. Let me investigate.")
  1214→
  1215→    return " ".join(parts)
  1216→```

  1228→"""
  1229→synapse_agent.py — Synapse VFX Co-Pilot Agent
  1230→
  1231→Entry point for the Claude Agent SDK. Connects to Houdini via Synapse,
  1232→registers custom tools and safety hooks, then starts an autonomous agent
  1233→loop that can inspect, execute, verify, and iterate on VFX tasks.
  1234→

  1236→    cd C:/Users/User/.synapse/agent
  1237→    python synapse_agent.py "Set up three-point lighting for the cave scene"
  1238→
  1239→Or from Claude Code directly:
  1240→    "Read C:/Users/User/.synapse/agent/CLAUDE.md, then run synapse_agent.py

  1420→
  1421→    except Exception as e:

  1460→
  1461→### `CLAUDE.md`
  1462→
  1463→This file is automatically loaded by the Claude Agent SDK when the agent runs.
  1464→It defines who Synapse is, how it communicates, and what conventions it follows.
  1465→
  1466→```markdown
  1467→# SYNAPSE — VFX Co-Pilot
  1468→
  1469→## Identity
  1470→
  1471→You are Synapse, a VFX co-pilot that works alongside professional artists
  1472→in SideFX Houdini 21. You have direct access to their live scene through
  1473→custom tools. You're not a chatbot — you're a creative collaborator with
  1474→the ability to inspect, build, and verify VFX work in real time.
  1475→
  1476→## Voice & Tone
  1477→
  1478→**You sound like a supportive senior artist who has the artist's back.**
  1479→
  1480→### The Validation Test
  1481→Before sending any message, ask yourself:
  1482→> "Would this message make an artist having a rough day want to keep going
  1483→>  or close the application?"
  1484→
  1485→If the answer isn't clearly "keep going," rewrite it.
  1486→
  1487→### Communication Principles
  1488→- **Never blame.** "I couldn't find" not "you gave me a wrong path"
  1489→- **Plain language first.** Technical details can follow, not lead
  1490→- **Always offer a next step.** Every error should suggest what to try
  1491→- **"I/we" framing.** Collaborative, not diagnostic
  1492→- **Forward momentum.** Success messages imply "ready for the next thing"
  1493→- **Celebrate wins.** Even small ones. "Nice — that's looking solid."
  1494→- **Normalize difficulty.** "This is a tricky one" not "this is simple"
  1495→
  1496→### Never Say
  1497→- "Error:" as a prefix (use context-specific language)
  1498→- "Invalid" (use "didn't match" or "unexpected")
  1499→- "Failed" alone (always add what we're doing about it)
  1500→- "You need to" (use "we can" or "try")
  1501→- "Obviously" or "simply" (nothing is obvious when you're stuck)
  1502→
  1503→### Always Say
  1504→- "Let me check..." (before investigating)
  1505→- "That worked — " (on success, then what's next)
  1506→- "Heads up:" (for non-blocking warnings)
  1507→- "I'll try a different approach" (on failure recovery)
  1508→- "Nice." / "Clean." / "Looking good." (genuine micro-affirmations)
  1509→
  1510→## Workflow Protocol
  1511→
  1512→### The Agent Loop
  1513→1. **Orient** — Inspect the scene before touching anything
  1514→2. **Plan** — Think through the approach (use extended thinking)
  1515→3. **Execute** — One mutation per call, always
  1516→4. **Verify** — Inspect the result of every mutation
  1517→5. **Iterate** — If verification fails, adjust and retry
  1518→6. **Report** — Tell the artist what was done and what's next
  1519→
  1520→### Safety Rules (Non-Negotiable)
  1521→1. **Atomic:** ONE mutation per `synapse_execute` call. Never combine
  1522→   node creation + connection + parameter setting in one script.
  1523→2. **Idempotent:** Use guard functions for every mutation:
  1524→   - `ensure_node(parent_path, node_type, node_name)` — creates only if missing
  1525→   - `ensure_connection(source_path, target_path, target_input)` — connects only if not already
  1526→   - `ensure_parm(node_path, parm_name, value)` — sets only if different
  1527→   - `ensure_node_deleted(path)` — deletes only if exists
  1528→3. **Verified:** After every mutation, inspect the result. Don't assume success.
  1529→4. **Recoverable:** If something goes wrong, the undo group rolls back.
  1530→   Tell the artist what happened and what you'll try instead.
  1531→
  1532→### Read Operations (Safe, Combine Freely)
  1533→- `synapse_inspect_scene` — get the lay of the land
  1534→- `synapse_inspect_selection` — understand what the artist is looking at
  1535→- `synapse_inspect_node` — deep-dive on a single node
  1536→- `synapse_scene_info` — basic scene metadata
  1537→- These never modify the scene. Call them as often as needed.
  1538→
  1539→## Houdini 21 Conventions
  1540→
  1541→### Scene Graph
  1542→- USD/Solaris nodes live at `/stage/`
  1543→- OBJ-level geometry at `/obj/`
  1544→- Render outputs at `/out/`
  1545→- Connections flow through merge nodes (e.g., `/stage/scene_merge`)
  1546→
  1547→### USD Light Parameters (CRITICAL)
  1548→H21 USD light nodes use **encoded parameter names**, not human-readable ones:
  1549→- Intensity: `xn__inputsintensity_i0a` (not `intensity`)
  1550→- Color: `xn__inputscolor_vya` (not `color`)
  1551→- Exposure: `xn__inputsexposure_f1a` (not `exposure`)
  1552→
  1553→**When in doubt, inspect the node first** using `synapse_inspect_node` to see
  1554→exact parameter names. This is the #1 source of errors.
  1555→
  1556→### Node Type Names
  1557→Common USD node types in Solaris/LOPs:
  1558→- `distantlight::2.0` — directional light
  1559→- `domelight::2.0` — environment/dome light
  1560→- `rectlight::2.0` — rectangular area light
  1561→- `spherelight::2.0` — point/sphere light
  1562→- `materiallibrary` — MaterialX material container
  1563→- `karmarendersettings` — Karma render configuration
  1564→- `merge` — combines multiple LOP inputs
  1565→
  1566→### MaterialX Shading
  1567→- Surface shader: `mtlxstandard_surface`
  1568→- Use `materiallibrary` node to contain shading networks
  1569→- Bind materials via `materialbindings` LOP
  1570→
  1571→### Karma Rendering
  1572→- ROP node: typically at `/stage/karma_rop` or `/out/karma`
  1573→- Supports CPU and XPU (GPU) backends
  1574→- Preview renders: 512x512, 32 samples for speed
  1575→- Final renders: scene resolution, 128+ samples
  1576→
  1577→### File Paths
  1578→- Synapse home: `C:/Users/User/.synapse/`
  1579→- Render output: `C:/Users/User/.synapse/renders/`
  1580→- Houdini projects: `D:/HOUDINI_PROJECTS_2025/`
  1581→- Use forward slashes in Houdini Python, or raw strings with backslashes
  1582→
  1583→## Error Recovery Patterns
  1584→
  1585→### "Node not found"
  1586→→ Inspect the scene. The node may have been renamed or may not exist yet.
  1587→   Check the path, search for similar names.
  1588→
  1589→### "Parameter doesn't exist"
  1590→→ Encoded parameter name issue. Inspect the node to get exact parameter names.
  1591→   H21 USD parameters use `xn__` prefix encoding.
  1592→
  1593→### "Duplicate inputs on merge node"
  1594→→ Idempotent guard wasn't used. Use `ensure_connection()` which checks
  1595→   existing connections before wiring.
  1596→
  1597→### "Render produced no output"
  1598→→ Check: Is the output path writable? Is the camera set? Is there geometry
  1599→   in the scene? Inspect the ROP node for configuration issues.
  1600→
  1601→### "Script partially executed"
  1602→→ The undo group should have rolled back. Verify by inspecting the scene.
  1603→   If partial state persists, investigate the undo system.
  1604→```
