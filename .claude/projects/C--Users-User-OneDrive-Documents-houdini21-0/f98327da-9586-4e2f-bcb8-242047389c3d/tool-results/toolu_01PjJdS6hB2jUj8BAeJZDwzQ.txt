     6→## Preamble: v3.0 → v4.0 Thesis
     7→
     8→v3.0 established the **Software Architecture**: typed protocols, validated data flow,
     9→registry-based extensibility, standalone optics library, HDA-wrapped Copernicus kernels.
    10→
    11→v4.0 adds the **Physical Architecture**. The camera rig stops being a "3D camera" and
    12→becomes a **Virtual Cinematography Simulator** where every compositor, lighter, and layout
    13→artist speaks the exact same language as a physical camera department.
    14→
    15→### What v4.0 Adds
    16→
    17→| Pillar | Problem v3.0 Doesn't Solve | v4.0 Solution |
    18→|--------|---------------------------|---------------|
    19→| **A. MechanicalSpec** | LensSpec has no physical dimensions | New `MechanicalSpec` dataclass + JSON schema evolution |
    20→| **B. Nodal Parallax** | CG camera pivots at sensor plane | Nested USD Xform hierarchy with entrance pupil offset |
    21→| **C. Operator Biomechanics** | Digital cameras have zero mass | CHOPs spring/lag solver driven by combined rig weight |
    22→| **D. CVEX Lens Shader** | Post-process distortion ruins DOF/mblur | Karma CVEX shader warps rays before scene sampling |
    23→| **E. Pipeline Bridge** | No downstream metadata for comp | Cooke /i + ASWF standard EXR header authoring |
    24→| **F. Dynamic Mumps** | Static squeeze_ratio = 2.0 at all distances | Focus-dependent squeeze curve (SqueezeBreathingCurve) |
    25→| **G. Copernicus 2.0** | Basic grain/flare effects | FFT convolution flares, sensor noise model, STMap AOV |
    26→
    27→### Dependency Chain
    28→
    29→```
    30→MechanicalSpec (A)
    31→    ├─→ Nodal Parallax (B)     — reads entrance_pupil_offset_mm
    32→    ├─→ Biomechanics (C)       — reads weight_kg, length_mm
    33→    └─→ CVEX Lens Shader (D)   — reads entrance_pupil_offset_mm
    34→Dynamic Mumps (F)
    35→    └─→ CVEX Lens Shader (D)   — reads dynamic squeeze at focus distance
    36→Pipeline Bridge (E)
    37→    └─→ depends on all above being authored to USD
    38→Copernicus 2.0 (G)
    39→    └─→ reads MechanicalSpec for FFT flare geometry
    40→```

   104→### A.1 New Dataclasses
   105→
   106→```python
   107→# File: python/cinema_camera/protocols.py  (ADDITIONS to v3.0)
   108→# ════════════════════════════════════════════════════════════
   109→# v4.0 MECHANICAL VALUE TYPES
   110→# ════════════════════════════════════════════════════════════
   111→
   112→@dataclass(frozen=True)
   113→class GearRingSpec:
   114→    """Physical gear ring on a cinema lens barrel."""
   115→    rotation_deg: float         # Total rotation travel
   116→    gear_teeth: int             # Tooth count for follow-focus motors
   117→    gear_module: float = 0.8   # Standard cine gear module (0.8mm pitch)
   118→
   119→    def __post_init__(self):
   120→        if self.rotation_deg <= 0 or self.rotation_deg > 360:
   121→            raise ValueError(f"Invalid gear rotation: {self.rotation_deg}°")
   122→        if self.gear_teeth <= 0:
   123→            raise ValueError(f"Invalid gear tooth count: {self.gear_teeth}")
   124→        if self.gear_module <= 0:
   125→            raise ValueError(f"Invalid gear module: {self.gear_module}")
   126→
   127→    @property
   128→    def pitch_circle_diameter_mm(self) -> float:
   129→        """PCD = module × teeth. Used for follow-focus motor compatibility."""
   130→        return self.gear_module * self.gear_teeth
   131→
   132→    @property
   133→    def degrees_per_tooth(self) -> float:
   134→        """Angular resolution of the gear ring."""
   135→        return self.rotation_deg / self.gear_teeth
   136→
   137→
   138→@dataclass(frozen=True)
   139→class MechanicalSpec:
   140→    """
   141→    Physical dimensions and mechanics of a cinema lens.
   142→    Required for biomechanics simulation and nodal parallax.
   143→    """
   144→    weight_kg: float
   145→    length_mm: float
   146→    front_diameter_mm: float
   147→    filter_thread: str                              # e.g. "M105x0.75"
   148→    focus_ring: GearRingSpec
   149→    iris_ring: GearRingSpec
   150→    entrance_pupil_offset_mm: float                 # Distance from sensor plane
   151→                                                    # to nodal point. CRITICAL for
   152→                                                    # parallax-correct panning.
   153→
   154→    def __post_init__(self):
   155→        if self.weight_kg <= 0:
   156→            raise ValueError(f"Invalid weight: {self.weight_kg}kg")
   157→        if self.length_mm <= 0:
   158→            raise ValueError(f"Invalid length: {self.length_mm}mm")
   159→        if self.front_diameter_mm <= 0:
   160→            raise ValueError(f"Invalid front diameter: {self.front_diameter_mm}mm")
   161→        if self.entrance_pupil_offset_mm < 0:
   162→            raise ValueError(
   163→                f"Invalid entrance pupil offset: {self.entrance_pupil_offset_mm}mm"
   164→            )
   165→
   166→    @property
   167→    def weight_lbs(self) -> float:
   168→        return self.weight_kg * 2.20462
   169→
   170→    @property
   171→    def entrance_pupil_offset_cm(self) -> float:
   172→        """USD uses centimeters for transforms."""
   173→        return self.entrance_pupil_offset_mm / 10.0
   174→```

   176→### A.2 SqueezeBreathingCurve (Dynamic Mumps — Pillar F)
   177→
   178→```python
   179→@dataclass(frozen=True)
   180→class SqueezeBreathingCurve:
   181→    """
   182→    Focus-dependent anamorphic squeeze variation ("Mumps").
   183→
   184→    Front-anamorphic lenses like Cooke Anamorphic/i only achieve their
   185→    nominal squeeze ratio at infinity focus. As focus distance decreases
   186→    toward MOD (Minimum Object Distance), the effective squeeze drops.
   187→
   188→    This creates the characteristic "mumps" effect — actors' faces appear
   189→    wider at close focus distances.
   190→
   191→    Points: ((focus_m, effective_squeeze), ...) sorted by focus_m ascending.
   192→    """
   193→    points: tuple[tuple[float, float], ...]  # ((focus_m, squeeze), ...)
   194→    nominal_squeeze: float = 2.0
   195→
   196→    def __post_init__(self):
   197→        sorted_pts = tuple(sorted(self.points, key=lambda p: p[0]))
   198→        object.__setattr__(self, 'points', sorted_pts)
   199→        # Validate squeeze values are physically reasonable
   200→        for focus_m, squeeze in self.points:
   201→            if squeeze < 1.0 or squeeze > self.nominal_squeeze + 0.1:
   202→                raise ValueError(
   203→                    f"Invalid squeeze {squeeze} at {focus_m}m "
   204→                    f"(nominal: {self.nominal_squeeze})"
   205→                )
   206→
   207→    def evaluate(self, focus_m: float) -> float:
   208→        """
   209→        Linear interpolation of effective squeeze at given focus distance.
   210→        Returns nominal_squeeze if no curve data or beyond curve range.
   211→        """
   212→        if not self.points:
   213→            return self.nominal_squeeze
   214→        if focus_m <= self.points[0][0]:
   215→            return self.points[0][1]
   216→        if focus_m >= self.points[-1][0]:
   217→            return self.points[-1][1]
   218→        for i in range(len(self.points) - 1):
   219→            f0, s0 = self.points[i]
   220→            f1, s1 = self.points[i + 1]
   221→            if f0 <= focus_m <= f1:
   222→                t = (focus_m - f0) / (f1 - f0) if f1 != f0 else 0
   223→                return s0 + t * (s1 - s0)
   224→        return self.nominal_squeeze
   225→```

   227→### A.3 Extended LensSpec (v4.0)
   228→
   229→```python
   230→@dataclass(frozen=True)
   231→class LensSpec:
   232→    """
   233→    Complete lens specification — v4.0 with mechanical data.
   234→    BACKWARDS COMPATIBLE: mechanics and squeeze_breathing are Optional
   235→    with sensible defaults so v3.0 JSON files still load.
   236→    """
   237→    # ── v3.0 fields (unchanged) ──────────────────────────
   238→    lens_id: str
   239→    manufacturer: str
   240→    series: str
   241→    focal_length_mm: float
   242→    t_stop_min: float
   243→    t_stop_max: float
   244→    iris_blades: int
   245→    close_focus_m: float
   246→    image_circle_mm: float
   247→    squeeze_ratio: float          # Nominal squeeze (1.0 spherical, 2.0 anamorphic)
   248→    distortion: DistortionModel
   249→    breathing: BreathingCurve
   250→    lateral_ca_px_per_mm: float = 0.0
   251→    longitudinal_ca_stops: float = 0.0
   252→
   253→    # ── v3.0 physical fields (now superseded by MechanicalSpec) ──
   254→    weight_kg: float = 0.0
   255→    length_mm: float = 0.0
   256→    front_diameter_mm: float = 0.0
   257→
   258→    # ── v4.0 additions ───────────────────────────────────
   259→    mechanics: Optional[MechanicalSpec] = None
   260→    squeeze_breathing: Optional[SqueezeBreathingCurve] = None
   261→
   262→    def __post_init__(self):
   263→        if self.focal_length_mm <= 0:
   264→            raise ValueError(f"Invalid focal length: {self.focal_length_mm}mm")
   265→        if self.t_stop_min <= 0 or self.t_stop_max <= self.t_stop_min:
   266→            raise ValueError(f"Invalid T-stop range: {self.t_stop_min}-{self.t_stop_max}")
   267→        if self.squeeze_ratio < 1.0:
   268→            raise ValueError(f"Invalid squeeze ratio: {self.squeeze_ratio}")
   269→        # Backfill v3.0 physical fields from MechanicalSpec if available
   270→        if self.mechanics and self.weight_kg == 0.0:
   271→            object.__setattr__(self, 'weight_kg', self.mechanics.weight_kg)
   272→            object.__setattr__(self, 'length_mm', self.mechanics.length_mm)
   273→            object.__setattr__(self, 'front_diameter_mm', self.mechanics.front_diameter_mm)
   274→
   275→    @property
   276→    def is_anamorphic(self) -> bool:
   277→        return self.squeeze_ratio > 1.01
   278→
   279→    @property
   280→    def has_mechanics(self) -> bool:
   281→        return self.mechanics is not None
   282→
   283→    @property
   284→    def entrance_pupil_offset_mm(self) -> float:
   285→        """Returns entrance pupil offset, or 0 if no mechanical data."""
   286→        return self.mechanics.entrance_pupil_offset_mm if self.mechanics else 0.0
   287→
   288→    def effective_squeeze(self, focus_distance_m: float) -> float:
   289→        """
   290→        Dynamic squeeze at given focus distance.
   291→        Returns nominal squeeze_ratio if no breathing curve.
   292→        """
   293→        if self.squeeze_breathing:
   294→            return self.squeeze_breathing.evaluate(focus_distance_m)
   295→        return self.squeeze_ratio
   296→```

   298→### A.4 Extended LensState (v4.0)
   299→
   300→```python
   301→@dataclass(frozen=True)
   302→class LensState:
   303→    """Lens state at a single frame — v4.0 with dynamic squeeze."""
   304→    spec: LensSpec
   305→    t_stop: float
   306→    focus_distance_m: float
   307→
   308→    def __post_init__(self):
   309→        if self.t_stop < self.spec.t_stop_min or self.t_stop > self.spec.t_stop_max:
   310→            raise ValueError(
   311→                f"T-stop {self.t_stop} outside range "
   312→                f"[{self.spec.t_stop_min}, {self.spec.t_stop_max}]"
   313→            )
   314→        if self.focus_distance_m < self.spec.close_focus_m:
   315→            raise ValueError(
   316→                f"Focus {self.focus_distance_m}m below close focus {self.spec.close_focus_m}m"
   317→            )
   318→
   319→    @property
   320→    def breathing_shift_pct(self) -> float:
   321→        return self.spec.breathing.evaluate(self.focus_distance_m)
   322→
   323→    @property
   324→    def effective_squeeze(self) -> float:
   325→        """Dynamic squeeze ratio at current focus distance (Mumps)."""
   326→        return self.spec.effective_squeeze(self.focus_distance_m)
   327→
   328→    @property
   329→    def entrance_pupil_offset_cm(self) -> float:
   330→        """Entrance pupil offset in USD centimeters."""
   331→        return self.spec.entrance_pupil_offset_mm / 10.0
   332→
   333→    @property
   334→    def rig_weight_kg(self) -> float:
   335→        """Total lens weight (body weight added at assembly level)."""
   336→        return self.spec.weight_kg
   337→
   338→    def to_usd_dict(self) -> dict[str, tuple[str, Any]]:
   339→        """Flat dictionary for USD attribute authoring — v4.0 extended."""
   340→        prefix = "cinema:lens"
   341→        d = self.spec.distortion
   342→        result = {
   343→            f"{prefix}:manufacturer":        ("String", self.spec.manufacturer),
   344→            f"{prefix}:series":              ("String", self.spec.series),
   345→            f"{prefix}:focalLengthMm":       ("Float",  self.spec.focal_length_mm),
   346→            f"{prefix}:squeezeRatioNominal": ("Float",  self.spec.squeeze_ratio),
   347→            f"{prefix}:squeezeRatioEffective": ("Float", self.effective_squeeze),
   348→            f"{prefix}:tStop":               ("Float",  self.t_stop),
   349→            f"{prefix}:focusDistanceM":      ("Float",  self.focus_distance_m),
   350→            f"{prefix}:irisBlades":          ("Int",    self.spec.iris_blades),
   351→            f"{prefix}:distortion:k1":       ("Float",  d.k1),
   352→            f"{prefix}:distortion:k2":       ("Float",  d.k2),
   353→            f"{prefix}:distortion:k3":       ("Float",  d.k3),
   354→            f"{prefix}:distortion:p1":       ("Float",  d.p1),
   355→            f"{prefix}:distortion:p2":       ("Float",  d.p2),
   356→            f"{prefix}:distortion:sqUniformity": ("Float", d.squeeze_uniformity),
   357→        }
   358→        # v4.0 mechanical attributes
   359→        if self.spec.has_mechanics:
   360→            m = self.spec.mechanics
   361→            result.update({
   362→                f"{prefix}:weightKg":            ("Float", m.weight_kg),
   363→                f"{prefix}:lengthMm":            ("Float", m.length_mm),
   364→                f"{prefix}:frontDiameterMm":     ("Float", m.front_diameter_mm),
   365→                f"{prefix}:entrancePupilOffsetMm": ("Float", m.entrance_pupil_offset_mm),
   366→                f"{prefix}:focusRingRotationDeg":  ("Float", m.focus_ring.rotation_deg),
   367→                f"{prefix}:irisRingRotationDeg":   ("Float", m.iris_ring.rotation_deg),
   368→            })
   369→        return result
   370→```

   636→## PILLAR B: Nodal Parallax (USD Transform Hierarchy)
   637→
   638→**Owner:** AGENT β (USD/Solaris)
   639→**Depends on:** Pillar A (MechanicalSpec)
   640→**Consumed by:** Pillar D (CVEX shader reads entrance pupil), Pillar E (metadata)
   641→
   642→### B.1 The Problem
   643→
   644→A CG camera rotates around its sensor plane origin. A physical camera on a tripod
   645→rotates around the fluid head pivot point, while the entrance pupil (nodal point) sits
   646→far ahead in the lens barrel. This mismatch causes CG elements to "slip" against
   647→live-action plates during pan/tilt operations or heavy focus pulls.
   648→
   649→### B.2 USD Xform Hierarchy
   650→
   651→```
   652→/World/CameraRig                              ← RIG ROOT (user transforms this)
   653→  └─/World/CameraRig/FluidHead                ← PIVOT POINT (pan/tilt origin)
   654→      ├─ xformOp:rotateXYZ = (tilt, pan, 0)
   655→      │
   656→      └─/World/CameraRig/FluidHead/Body       ← CAMERA BODY (sensor plane)
   657→          ├─ xformOp:translate = (0, body_offset_y, -sensor_offset_z)
   658→          │   body_offset_y: height from head baseplate to sensor center
   659→          │   sensor_offset_z: distance from mounting face to sensor plane
   660→          │
   661→          └─/World/CameraRig/FluidHead/Body/Sensor  ← UsdGeom.Camera
   662→              ├─ horizontalAperture, verticalAperture, focalLength ...
   663→              ├─ cinema:rig:entrancePupilOffsetCm  (authored from MechanicalSpec)
   664→              ├─ cinema:rig:combinedWeightKg       (body + lens)
   665→              ├─ cinema:rig:fluidHeadModel         (e.g. "OConnor 2575")
   666→              │
   667→              └─/World/CameraRig/FluidHead/Body/Sensor/EntrancePupil  ← NODAL POINT
   668→                  ├─ xformOp:translate = (0, 0, entrance_pupil_offset_cm)
   669→                  └─ purpose = "guide"  (viewport visualization only)
   670→```
   671→
   672→### B.3 Refactored USD Builder
   673→
   674→```python
   675→# File: python/cinema_camera/usd_builder.py (v4.0 — REPLACES v3.0 build_usd_camera)
   676→
   677→from __future__ import annotations
   678→from pxr import Usd, UsdGeom, UsdRender, Sdf, Gf
   679→from .protocols import CameraState, LensState, OpticalResult
   680→
   681→
   682→# ── Attribute type mapping ────────────────────────────────
   683→_USD_TYPE_MAP = {
   684→    "String": Sdf.ValueTypeNames.String,
   685→    "Float":  Sdf.ValueTypeNames.Float,
   686→    "Int":    Sdf.ValueTypeNames.Int,
   687→    "Bool":   Sdf.ValueTypeNames.Bool,
   688→}
   689→
   690→
   691→def _author_attributes(prim: Usd.Prim, attrs: dict[str, tuple[str, object]]) -> None:
   692→    """Author a dict of {name: (type_str, value)} onto a USD prim."""
   693→    for attr_name, (type_str, value) in attrs.items():
   694→        sdf_type = _USD_TYPE_MAP.get(type_str)
   695→        if sdf_type is None:
   696→            continue
   697→        attr = prim.GetAttribute(attr_name)
   698→        if not attr:
   699→            attr = prim.CreateAttribute(attr_name, sdf_type)
   700→        attr.Set(value)
   701→
   702→
   703→# ── Body offset constants (mm → cm) ─────────────────────
   704→# Distance from tripod quick-release plate to sensor center
   705→_BODY_OFFSETS_CM = {
   706→    "ARRI ALEXA 35":   {"y": 5.0, "z": -8.0},   # 80mm mount-face to sensor
   707→    "RED KOMODO":      {"y": 3.5, "z": -5.0},
   708→    "SONY VENICE 2":   {"y": 5.5, "z": -9.0},
   709→}
   710→_DEFAULT_BODY_OFFSET = {"y": 4.0, "z": -7.0}
   711→
   712→
   713→def build_usd_camera_rig(
   714→    stage: Usd.Stage,
   715→    rig_path: str,
   716→    camera_state: CameraState,
   717→    lens_state: LensState,
   718→    optical_result: OpticalResult,
   719→    fluid_head_model: str = "OConnor 2575",
   720→) -> UsdGeom.Camera:
   721→    """
   722→    Build a physically-nested USD camera rig from typed state objects.
   723→
   724→    Hierarchy:
   725→      {rig_path}/FluidHead/Body/Sensor/EntrancePupil
   726→
   727→    The FluidHead prim is the pan/tilt pivot.
   728→    The Sensor prim is the UsdGeom.Camera.
   729→    The EntrancePupil is a guide Xform for parallax visualization.
   730→
   731→    Returns the UsdGeom.Camera (Sensor prim).
   732→    """
   733→
   734→    # ── 1. Rig Root ──────────────────────────────────────
   735→    rig_root = UsdGeom.Xform.Define(stage, rig_path)
   736→
   737→    # ── 2. Fluid Head (Pan/Tilt Pivot) ───────────────────
   738→    head_path = f"{rig_path}/FluidHead"
   739→    head = UsdGeom.Xform.Define(stage, head_path)
   740→    head.GetPrim().CreateAttribute(
   741→        "cinema:rig:fluidHeadModel", Sdf.ValueTypeNames.String
   742→    ).Set(fluid_head_model)
   743→
   744→    # ── 3. Camera Body (Offset from Head) ────────────────
   745→    body_path = f"{head_path}/Body"
   746→    body = UsdGeom.Xform.Define(stage, body_path)
   747→    offsets = _BODY_OFFSETS_CM.get(camera_state.model, _DEFAULT_BODY_OFFSET)
   748→    UsdGeom.XformCommonAPI(body).SetTranslate(
   749→        Gf.Vec3d(0, offsets["y"], offsets["z"])
   750→    )
   751→
   752→    # ── 4. Sensor (UsdGeom.Camera) ───────────────────────
   753→    sensor_path = f"{body_path}/Sensor"
   754→    camera = UsdGeom.Camera.Define(stage, sensor_path)
   755→
   756→    # Core USD camera attributes
   757→    camera.CreateProjectionAttr().Set(UsdGeom.Tokens.perspective)
   758→    camera.CreateHorizontalApertureAttr().Set(camera_state.active_width_mm)
   759→    camera.CreateVerticalApertureAttr().Set(camera_state.active_height_mm)
   760→    camera.CreateFocalLengthAttr().Set(lens_state.spec.focal_length_mm)
   761→    camera.CreateFocusDistanceAttr().Set(lens_state.focus_distance_m * 100)  # m → cm
   762→    camera.CreateFStopAttr().Set(lens_state.t_stop)
   763→    camera.CreateClippingRangeAttr().Set(Gf.Vec2f(0.01, 100000.0))
   764→
   765→    # Custom cinema attributes on camera prim
   766→    prim = camera.GetPrim()
   767→    _author_attributes(prim, camera_state.to_usd_dict())
   768→    _author_attributes(prim, lens_state.to_usd_dict())
   769→    _author_attributes(prim, {
   770→        "cinema:optics:hfovDeg":     ("Float", optical_result.hfov_deg),
   771→        "cinema:optics:vfovDeg":     ("Float", optical_result.vfov_deg),
   772→        "cinema:optics:dofNearM":    ("Float", optical_result.dof_near_m),
   773→        "cinema:optics:dofFarM":     ("Float", optical_result.dof_far_m),
   774→        "cinema:optics:hyperfocalM": ("Float", optical_result.hyperfocal_m),
   775→        "cinema:optics:cocMm":       ("Float", optical_result.coc_mm),
   776→    })
   777→
   778→    # Rig-level metadata on camera prim
   779→    combined_weight = lens_state.rig_weight_kg
   780→    # If camera body weight is known (could be added to CameraState in future)
   781→    _author_attributes(prim, {
   782→        "cinema:rig:entrancePupilOffsetCm": ("Float", lens_state.entrance_pupil_offset_cm),
   783→        "cinema:rig:combinedWeightKg":      ("Float", combined_weight),
   784→        "cinema:rig:effectiveSqueeze":       ("Float", lens_state.effective_squeeze),
   785→    })
   786→
   787→    # ── 5. Entrance Pupil (Guide Visualization) ──────────
   788→    pupil_path = f"{sensor_path}/EntrancePupil"
   789→    pupil = UsdGeom.Xform.Define(stage, pupil_path)
   790→    UsdGeom.XformCommonAPI(pupil).SetTranslate(
   791→        Gf.Vec3d(0, 0, lens_state.entrance_pupil_offset_cm)
   792→    )
   793→    pupil.GetPrim().CreateAttribute(
   794→        "purpose", Sdf.ValueTypeNames.Token
   795→    ).Set("guide")
   796→
   797→    return camera
   798→
   799→
   800→# ── Backwards-compatible wrapper ─────────────────────────
   801→def build_usd_camera(
   802→    stage: Usd.Stage,
   803→    camera_path: str,
   804→    camera_state: CameraState,
   805→    lens_state: LensState,
   806→    optical_result: OpticalResult,
   807→) -> UsdGeom.Camera:
   808→    """
   809→    v3.0 compatible entry point. Delegates to build_usd_camera_rig
   810→    with the camera_path as rig root. Returns UsdGeom.Camera.
   811→    """
   812→    return build_usd_camera_rig(
   813→        stage, camera_path, camera_state, lens_state, optical_result
   814→    )
   815→```

   840→## PILLAR C: Operator Biomechanics Engine (CHOPs)
   841→
   842→**Owner:** AGENT δ (CHOPs/Copernicus)
   843→**Depends on:** Pillar A (weight_kg), Pillar B (USD rig hierarchy)
   844→
   845→### C.1 The Problem
   846→
   847→A 50mm Cooke at 3.6kg on an Alexa 35 (3.9kg) = 7.5kg rig. A 300mm at 9.4kg = 13.3kg.
   848→The 13.3kg rig has massive rotational inertia — pans ease in slowly and coast to a stop.
   849→The 7.5kg rig is snappy and jittery. Digital cameras have none of this.
   850→
   851→### C.2 CHOPs Constraint Architecture
   852→
   853→```
   854→cinema::chops_biomechanics::1.0  [CHOP Network inside top-level HDA]
   855→
   856→    ┌───────────────┐
   857→    │ Input: Raw     │ ← Pan/Tilt/Roll animation channels
   858→    │ Camera Motion  │   from animator or mocap
   859→    └───────┬───────┘
   860→            │
   861→    ┌───────▼───────────────┐
   862→    │ Inertia Calculator    │ ← Reads cinema:rig:combinedWeightKg
   863→    │                       │   from USD attribute via spare parm
   864→    │ moment_of_inertia =   │
   865→    │   weight_kg *         │
   866→    │   (arm_length_cm)^2   │   arm_length = sensor_offset + pupil_offset
   867→    └───────┬───────────────┘
   868→            │
   869→    ┌───────▼───────────────┐
   870→    │ CHOP Spring Solver    │ ← spring_constant = fn(head_friction)
   871→    │                       │   damping = fn(moment_of_inertia)
   872→    │ Heavy rig:            │   = high damping, slow response
   873→    │   spring_k = 8.0      │   
   874→    │   damping = 0.85      │   
   875→    │ Light rig:            │   = low damping, snappy
   876→    │   spring_k = 15.0     │   
   877→    │   damping = 0.4       │   
   878→    └───────┬───────────────┘
   879→            │
   880→    ┌───────▼───────────────┐
   881→    │ CHOP Lag Solver       │ ← Simulates operator reaction time
   882→    │                       │   lag_frames = weight_kg * 0.3
   883→    │ Adds onset delay      │   
   884→    └───────┬───────────────┘
   885→            │
   886→    ┌───────▼───────────────┐
   887→    │ High-Freq Noise       │ ← Handheld camera shake
   888→    │ (Optional)            │   amplitude = fn(1/weight_kg)
   889→    │                       │   Heavy rig = less shake
   890→    │                       │   Light rig = more shake
   891→    └───────┬───────────────┘
   892→            │
   893→    ┌───────▼───────┐
   894→    │ Output: Phys   │ → Drives FluidHead xformOp:rotateXYZ
   895→    │ Camera Motion  │   via CHOP export or LOP wrangle
   896→    └───────────────┘
   897→```
   898→
   899→### C.3 Biomechanics Parameter Derivation
   900→
   901→```python
   902→# File: python/cinema_camera/biomechanics.py
   903→"""
   904→Operator biomechanics parameter derivation.
   905→Converts physical rig properties into CHOPs solver parameters.
   906→"""
   907→
   908→from __future__ import annotations
   909→from dataclasses import dataclass
   910→from .protocols import CameraState, LensState
   911→
   912→
   913→@dataclass(frozen=True)
   914→class BiomechanicsParams:
   915→    """CHOPs solver parameters derived from physical rig properties."""
   916→    # Spring solver
   917→    spring_constant: float      # Higher = snappier response
   918→    damping_ratio: float        # 0-1: 0=undamped, 1=critically damped
   919→
   920→    # Lag solver
   921→    lag_frames: float           # Operator reaction delay
   922→
   923→    # Noise (handheld)
   924→    handheld_amplitude_deg: float  # Peak random rotation
   925→    handheld_frequency_hz: float   # Dominant shake frequency
   926→
   927→    # Derived
   928→    moment_of_inertia: float    # kg·cm² (for reference)
   929→    combined_weight_kg: float
   930→
   931→
   932→def derive_biomechanics(
   933→    camera_state: CameraState,
   934→    lens_state: LensState,
   935→    body_weight_kg: float = 3.9,             # ARRI Alexa 35 body
   936→    sensor_to_mounting_face_cm: float = 8.0,  # Distance sensor to mount
   937→    fluid_head_damping_base: float = 0.6,     # OConnor 2575 baseline
   938→) -> BiomechanicsParams:
   939→    """
   940→    Derive CHOPs parameters from physical rig properties.
   941→
   942→    The key insight: rotational inertia scales with mass × distance².
   943→    A heavy lens pushes the center of mass forward, increasing the
   944→    moment arm and dramatically increasing rotational inertia.
   945→    """
   946→    lens_weight = lens_state.rig_weight_kg
   947→    combined_weight = body_weight_kg + lens_weight
   948→
   949→    # Moment arm: distance from tripod pivot to center of mass
   950→    # Approximate: sensor offset + half lens length
   951→    lens_half_length_cm = 0.0
   952→    if lens_state.spec.has_mechanics:
   953→        lens_half_length_cm = lens_state.spec.mechanics.length_mm / 20.0  # mm→cm/2
   954→
   955→    moment_arm_cm = sensor_to_mounting_face_cm + lens_half_length_cm
   956→    moment_of_inertia = combined_weight * (moment_arm_cm ** 2)
   957→
   958→    # Spring constant: inversely proportional to inertia
   959→    # Calibrated so 7kg rig ≈ 15.0, 15kg rig ≈ 8.0
   960→    spring_k = max(5.0, 25.0 - moment_of_inertia * 0.012)
   961→
   962→    # Damping: heavier rigs are more critically damped
   963→    damping = min(0.95, fluid_head_damping_base + combined_weight * 0.025)
   964→
   965→    # Lag: heavier rigs have slower operator response
   966→    lag_frames = combined_weight * 0.3
   967→
   968→    # Handheld shake: inversely proportional to weight
   969→    handheld_amp = max(0.05, 1.5 / combined_weight)
   970→    handheld_freq = max(2.0, 8.0 - combined_weight * 0.3)
   971→
   972→    return BiomechanicsParams(
   973→        spring_constant=spring_k,
   974→        damping_ratio=damping,
   975→        lag_frames=lag_frames,
   976→        handheld_amplitude_deg=handheld_amp,
   977→        handheld_frequency_hz=handheld_freq,
   978→        moment_of_inertia=moment_of_inertia,
   979→        combined_weight_kg=combined_weight,
   980→    )
   981→```

  1005→## PILLAR D: Karma CVEX Lens Shader
  1006→
  1007→**Owner:** AGENT γ (VEX/CVEX)
  1008→**Depends on:** Pillar A (MechanicalSpec for pupil offset), Pillar F (dynamic squeeze)
  1009→
  1010→### D.1 The Problem
  1011→
  1012→Applying distortion in Copernicus (post-process) stretches pixels. This destroys
  1013→depth-of-field accuracy, motion blur fidelity, and refractive caustics. The correct
  1014→approach is to warp the camera rays *before* they sample the scene.
  1015→
  1016→### D.2 libcinema_optics.h Extensions (Dynamic Squeeze)
  1017→
  1018→```c
  1019→// File: vex/libcinema_optics.h (v4.0 ADDITIONS)
  1020→
  1021→// ── Dynamic Squeeze (Mumps) ────────────────────────────
  1022→
  1023→// PERF: O(n) where n = curve points | <0.001ms | Memory: negligible
  1024→float co_evaluate_squeeze_curve(
  1025→    float focus_m;
  1026→    float curve_focus[];       // Sorted focus distances (m)
  1027→    float curve_squeeze[];     // Corresponding squeeze values
  1028→    float nominal_squeeze      // Fallback if arrays empty
  1029→) {
  1030→    int n = len(curve_focus);
  1031→    if (n == 0) return nominal_squeeze;
  1032→    if (n != len(curve_squeeze)) return nominal_squeeze;  // guard
  1033→
  1034→    if (focus_m <= curve_focus[0]) return curve_squeeze[0];
  1035→    if (focus_m >= curve_focus[n-1]) return curve_squeeze[n-1];
  1036→
  1037→    for (int i = 0; i < n - 1; i++) {
  1038→        if (curve_focus[i] <= focus_m && focus_m <= curve_focus[i+1]) {
  1039→            float t = (focus_m - curve_focus[i]) /
  1040→                      (curve_focus[i+1] - curve_focus[i]);
  1041→            return lerp(curve_squeeze[i], curve_squeeze[i+1], t);
  1042→        }
  1043→    }
  1044→    return nominal_squeeze;
  1045→}
  1046→
  1047→
  1048→// ── Anamorphic Distortion with Dynamic Squeeze ─────────
  1049→
  1050→// PERF: O(1) per pixel | ~15ms @ 4K | Memory: negligible
  1051→vector2 co_apply_anamorphic_distortion(
  1052→    vector2 uv_centered;
  1053→    CO_DistortionCoeffs coeffs;
  1054→    float effective_squeeze     // Dynamic squeeze at current focus distance
  1055→) {
  1056→    float x = uv_centered.x;
  1057→    float y = uv_centered.y;
  1058→
  1059→    float r2 = x*x + y*y;
  1060→    float r4 = r2 * r2;
  1061→    float r6 = r4 * r2;
  1062→
  1063→    // Radial distortion (Brown-Conrady)
  1064→    float radial = 1.0 + coeffs.k1*r2 + coeffs.k2*r4 + coeffs.k3*r6;
  1065→
  1066→    // Tangential
  1067→    float dx = 2.0*coeffs.p1*x*y + coeffs.p2*(r2 + 2.0*x*x);
  1068→    float dy = coeffs.p1*(r2 + 2.0*y*y) + 2.0*coeffs.p2*x*y;
  1069→
  1070→    // Anamorphic squeeze non-uniformity (across frame)
  1071→    float sq_var = lerp(1.0, coeffs.squeeze_uniformity, r2);
  1072→
  1073→    // Dynamic squeeze applied to X axis
  1074→    // Nominal 2.0x → effective 1.85x at MOD for front-anamorphic
  1075→    float distorted_x = (x * radial + dx) * effective_squeeze;
  1076→    float distorted_y = (y * radial + dy) * sq_var;
  1077→
  1078→    return set(distorted_x, distorted_y);
  1079→}
  1080→```

  1082→### D.3 Karma CVEX Lens Shader
  1083→
  1084→```c
  1085→// File: vex/karma_cinema_lens.vfl
  1086→// ═══════════════════════════════════════════════════════════
  1087→// KARMA CVEX LENS SHADER — Cinema Camera Rig v4.0
  1088→//
  1089→// Warps render rays BEFORE scene sampling.
  1090→// This preserves DOF, motion blur, and refraction fidelity.
  1091→//
  1092→// Compiles to: cvex_cinema_lens.vex
  1093→// Usage: Assign as lens shader on Karma render settings
  1094→//
  1095→// Parameters read from USD camera prim attributes at render time.
  1096→// ═══════════════════════════════════════════════════════════
  1097→
  1098→#include <libcinema_optics.h>
  1099→
  1100→cvex cinema_lens_shader(
  1101→    // ── Lens parameters (driven from USD attributes) ────
  1102→    float focal_length_mm = 50.0;
  1103→    float effective_squeeze = 2.0;         // cinema:rig:effectiveSqueeze
  1104→    float entrance_pupil_offset_cm = 12.5; // cinema:rig:entrancePupilOffsetCm
  1105→    float sensor_width_mm = 27.99;         // horizontalAperture
  1106→    float sensor_height_mm = 19.22;        // verticalAperture
  1107→
  1108→    // Distortion coefficients (from cinema:lens:distortion:*)
  1109→    float dist_k1 = 0.0;
  1110→    float dist_k2 = 0.0;
  1111→    float dist_k3 = 0.0;
  1112→    float dist_p1 = 0.0;
  1113→    float dist_p2 = 0.0;
  1114→    float dist_sq_uniformity = 1.0;
  1115→
  1116→    // Enable/disable controls
  1117→    int enable_distortion = 1;
  1118→    int enable_squeeze = 1;
  1119→    int enable_pupil_offset = 1;
  1120→
  1121→    // ── Standard CVEX lens inputs ───────────────────────
  1122→    float x = 0.0;     // Screen-space X (-1 to 1)
  1123→    float y = 0.0;     // Screen-space Y (-1 to 1)
  1124→    float Time = 0.0;
  1125→    float sx = 0.0;    // Sub-pixel jitter X
  1126→    float sy = 0.0;    // Sub-pixel jitter Y
  1127→
  1128→    // ── Standard CVEX lens outputs ──────────────────────
  1129→    export vector P = {0, 0, 0};    // Ray origin (camera space)
  1130→    export vector I = {0, 0, 1};    // Ray direction (camera space)
  1131→    export int valid = 1;           // 1 = valid ray, 0 = discard
  1132→) {
  1133→    // ── Apply sub-pixel jitter ──────────────────────────
  1134→    float jx = x + sx;
  1135→    float jy = y + sy;
  1136→
  1137→    // ── Apply optical distortion to screen coordinates ──
  1138→    vector2 uv = set(jx, jy);
  1139→
  1140→    if (enable_distortion) {
  1141→        CO_DistortionCoeffs coeffs;
  1142→        coeffs.k1 = dist_k1;
  1143→        coeffs.k2 = dist_k2;
  1144→        coeffs.k3 = dist_k3;
  1145→        coeffs.p1 = dist_p1;
  1146→        coeffs.p2 = dist_p2;
  1147→        coeffs.squeeze_uniformity = dist_sq_uniformity;
  1148→
  1149→        if (enable_squeeze && effective_squeeze > 1.01) {
  1150→            // Dynamic anamorphic distortion with focus-dependent squeeze
  1151→            uv = co_apply_anamorphic_distortion(uv, coeffs, effective_squeeze);
  1152→        } else {
  1153→            // Standard spherical distortion
  1154→            uv = co_apply_distortion(uv, coeffs);
  1155→        }
  1156→    } else if (enable_squeeze && effective_squeeze > 1.01) {
  1157→        // Squeeze only, no distortion
  1158→        uv.x *= effective_squeeze;
  1159→    }
  1160→
  1161→    // ── Convert screen UV to camera-space ray direction ─
  1162→    // Map [-1,1] screen coords to sensor plane coordinates
  1163→    float half_w = sensor_width_mm * 0.5;
  1164→    float half_h = sensor_height_mm * 0.5;
  1165→
  1166→    float ray_x = uv.x * half_w;
  1167→    float ray_y = uv.y * half_h;
  1168→    float ray_z = focal_length_mm;
  1169→
  1170→    I = normalize(set(ray_x, ray_y, ray_z));
  1171→
  1172→    // ── Ray origin at entrance pupil ────────────────────
  1173→    // Physical rays originate at the nodal point, not sensor plane
  1174→    if (enable_pupil_offset) {
  1175→        // Entrance pupil is FORWARD from sensor (positive Z in camera space)
  1176→        // Convert cm to Houdini scene units (cm default in USD)
  1177→        P = set(0, 0, entrance_pupil_offset_cm);
  1178→    } else {
  1179→        P = set(0, 0, 0);
  1180→    }
  1181→
  1182→    valid = 1;
  1183→}

  1443→│   ├── Step 1: Threshold input → extract bright pixels
  1444→│   ├── Step 2: Generate iris kernel using co_generate_bokeh_kernel()
  1445→│   │           with iris_blades=11 and squeeze_ratio
  1446→│   ├── Step 3: FFT convolution of bright pixels × iris kernel
  1447→│   │           (produces physically accurate polygonal ghost patterns)
  1448→│   ├── Step 4: Anamorphic streak via horizontal Gaussian
  1449→│   │           stretched by front_diameter_mm / focal_length ratio
  1450→│   ├── Step 5: Chromatic fringing on ghosts (R/G/B offset)
  1451→│   └── Step 6: Composite flare over original
  1452→└── OUTPUT: Image with physically-based lens flare
  1453→```

  1455→### G.3 Sensor Noise Model (Replaces cop_film_grain)
  1456→
  1457→```
  1458→cinema::cop_sensor_noise::1.0  [Copernicus HDA]
  1459→├── INPUT 0: Image (RGBA)
  1460→├── Parameters:
  1461→│   ├── enable (Toggle)
  1462→│   ├── exposure_index (Int, from CameraState — drives noise level)
  1463→│   ├── native_iso (Int, from SensorSpec — 800 for Alexa 35)
  1464→│   ├── sensor_model (Menu: "ALEXA 35 Dual Gain" / "Generic CMOS" / "Custom")
  1465→│   ├── photon_noise_amount (Float, shot noise — sqrt of signal)
  1466→│   ├── read_noise_amount (Float, electronic noise — constant floor)
  1467→│   └── temporal_coherence (Float, 0=fully random per frame, 1=static)
  1468→├── Internal VEX:
  1469→│   ├── Photon noise: sqrt(luminance) × random × photon_amount
  1470→│   │   (physically: shot noise scales with square root of exposure)
  1471→│   ├── Read noise: constant random × read_amount × (EI / native_iso)
  1472→│   │   (higher EI amplifies read noise — dual-gain model)
  1473→│   ├── Per-channel application (Bayer-pattern awareness)
  1474→│   ├── Temporal: lerp(random, cached_noise[frame], temporal_coherence)
  1475→│   └── Grain size: 1px at native_iso, 2px at 2× native, etc.
  1476→└── OUTPUT: Image with physically-modeled sensor noise
  1477→```
