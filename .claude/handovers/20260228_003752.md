## Technical Notes

- **Synapse output**: No `print()` capture. Use `result = "..."` as last expression.
- **cop2net vs copnet**: `copnet` = Cop (legacy), `cop2net` = Cop2 (Copernicus). COP2 HDAs need cop2net.
- **HDA parm persistence**: Must use `hda_def.setParmTemplateGroup()` + `hda_def.updateFromNode()`. Node-level set doesn't persist for COP2/CHOP.
