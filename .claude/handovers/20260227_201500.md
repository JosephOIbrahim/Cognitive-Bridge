## Technical Notes
- **Synapse exec() scoping quirk**: Generator expressions inside `exec()` can't see local variables. Use explicit for-loops instead of `all(rig.node(n) for n in nodes)`.
- **Synapse .render() deadlock**: Calling `karma.render()` blocks the main thread which deadlocks `hdefereval`. Use `karma.parm('executebackground').pressButton()` instead -- it forks husk and the WebSocket disconnects but the render completes.
- **Module caching**: After editing builder .py files, must `importlib.reload(mod)` before rebuilding HDA in same Houdini session.
