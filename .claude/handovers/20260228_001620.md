## Technical Notes

- **Synapse output capture**: Synapse no longer returns `print()` output. It captures the last expression's value. Use `result = "..."` as the final line. The `houdini_exec.py` client reads `resp["data"]["result"]`.
- **cop2net vs copnet**: In Houdini 21, `copnet` creates a `Cop` category container (legacy). `cop2net` creates a `Cop2` category container (Copernicus). COP2-category HDAs only work inside `cop2net`.
- **HDA parm persistence**: `hda_node.setParmTemplateGroup(ptg)` sets parms on the instance but does NOT persist to definition for COP2/CHOP HDAs. Must use `hda_def.setParmTemplateGroup(ptg)` to set directly on the definition, then `hda_def.updateFromNode(hda_node)` to capture internal node state (expressions, connections).
- **All 5 HDA type names** (no version suffix): `cinema::camera_rig`, `cinema::cop_anamorphic_flare`, `cinema::cop_sensor_noise`, `cinema::cop_stmap_aov`, `cinema::chops_biomechanics`
- **Module reload required**: After editing builder .py files, must `importlib.reload(mod)` before rebuilding in same Houdini session.
- **Synapse `.render()` deadlocks**: Use `parm('executebackground').pressButton()` not `.render()`.
