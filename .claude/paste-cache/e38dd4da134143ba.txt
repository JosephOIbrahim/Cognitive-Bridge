## Section 1: Project Analysis

### Architecture Summary

SYNAPSE is an MCP server bridging Claude AI ↔ SideFX Houdini 21 via WebSocket (`ws://localhost:9999`). Core stats:

- **58 Python modules** | 22K+ LOC | 890 tests | 43 MCP tools
- **Safety layers:** atomic scripts, idempotent guards, transaction wrappers (undo-group rollback)
- **Memory system:** markdown → USD evolution based on usage patterns
- **Sprint orchestrator:** filesystem-driven state detection, auto-phase management
- **Comms:** WebSocket JSON-RPC, full `hou` module execution
- **Transition:** reactive MCP bridge → autonomous agent (Claude Agent SDK + PDG/TOPs)

### Pattern Relevance Assessment

| Pattern | Relevance | Rationale |
|---------|-----------|-----------|
| **1: Sparse Routing** | **HIGH** | 43 MCP tools. Dense tool matching is wasteful. Lightweight indexer pre-scores top-3 tools per request, full dispatch logic runs only on candidates. Direct latency win. |
| **2: Persistent Reasoning** | **HIGH** | Autonomous render agent chains 5-15 tool calls (create → parameterize → render → evaluate → adjust). Reasoning context (artistic intent, parameter history, evaluation criteria) must survive each tool boundary. This is THE missing piece for Agent SDK integration. |
| **3: Specialist Distillation** | **MEDIUM** | Domain tool categories exist (scene, lighting, materials, rendering, memory). Formalizing into specialist modes with domain-specific system prompts and verifiable rewards adds value but infrastructure partially exists via voice guide system. Graft as enhancement, not net-new. |
| **4: Agentic Task Synthesis** | **MEDIUM-HIGH** | PDG integration needs robust test coverage. Synthetic task generation (diverse scene setups, lighting challenges, material assignments, render evaluations) creates regression suite that manual test writing can't match. Critical for autonomous agent reliability. |

## Section 2: Implementation Blueprint

### Pattern 1: Sparse Tool Router

**Problem:** 43 tools evaluated densely per request. Most requests touch 1-3 tools.

**Solution:** Lightweight signal indexer pre-scores tool relevance, full dispatch runs only on top-k candidates.

#### File: `src/agent/sparse_router.py`

```python
"""
Sparse Tool Router — DeepSeek DSA pattern adapted for MCP tool dispatch.

Principle: Before expensive full evaluation of all 43 tools,
run a cheap classifier to identify the ~3 most relevant tools,
then only do deep matching on those.

Calibration: Run dense for N requests, collect ground truth,
tune indexer weights against actual tool selections.
"""

from __future__ import annotations

import json
import re
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any

# --- Data Structures ---

@dataclass(frozen=True)
class ToolSignature:
    """Lightweight tool fingerprint for cheap matching."""
    name: str
    domain: str                    # scene | lighting | material | render | memory | system
    keywords: frozenset[str]       # trigger words
    param_patterns: frozenset[str] # expected parameter names
    cost_tier: int                 # 1=read-only, 2=mutation, 3=render/heavy
    
@dataclass
class RouteCandidate:
    """Scored candidate from sparse indexer."""
    tool_name: str
    score: float
    match_signals: list[str] = field(default_factory=list)

@dataclass
class SparseRouterConfig:
    """Router tuning parameters."""
    top_k: int = 3                          # candidates passed to full dispatch
    keyword_weight: float = 0.4             # weight for keyword match
    domain_weight: float = 0.3              # weight for domain match  
    param_weight: float = 0.2               # weight for parameter pattern match
    recency_weight: float = 0.1             # weight for recently-used tools
    calibration_file: str = "router_calibration.json"

# --- Indexer ---

class SparseToolIndexer:
    """
    Lightweight pre-scorer for MCP tool selection.
    
    Phase 1 (DENSE — calibration):
        Runs full evaluation, logs actual selections as ground truth.
        
    Phase 2 (SPARSE — production):
        Runs cheap indexer, returns top-k candidates.
        Periodically validates against dense to prevent drift.
    """
    
    def __init__(self, config: SparseRouterConfig | None = None) -> None:
        self.config = config or SparseRouterConfig()
        self.signatures: dict[str, ToolSignature] = {}
        self.recency_buffer: list[str] = []  # last N tool selections
        self.calibration_data: list[dict[str, Any]] = []
        self._mode: str = "dense"  # "dense" | "sparse" | "hybrid"
        
    def register_tool(self, sig: ToolSignature) -> None:
        """Register a tool's lightweight signature."""
        self.signatures[sig.name] = sig
        
    def index(self, request: dict[str, Any]) -> list[RouteCandidate]:
        """
        Cheap pre-scoring pass. O(T) where T = number of tools.
        Returns top-k candidates sorted by score descending.
        """
        text = self._extract_text_signal(request)
        params = set(request.get("params", {}).keys())
        domain_hint = self._detect_domain(text)
        
        candidates: list[RouteCandidate] = []
        
        for name, sig in self.signatures.items():
            score = 0.0
            signals: list[str] = []
            
            # Keyword match (cheap string intersection)
            keyword_hits = sig.keywords & set(text.lower().split())
            if keyword_hits:
                score += self.config.keyword_weight * (len(keyword_hits) / max(len(sig.keywords), 1))
                signals.append(f"keywords:{','.join(keyword_hits)}")
            
            # Domain match
            if domain_hint and sig.domain == domain_hint:
                score += self.config.domain_weight
                signals.append(f"domain:{domain_hint}")
                
            # Parameter pattern match
            param_hits = sig.param_patterns & params
            if param_hits:
                score += self.config.param_weight * (len(param_hits) / max(len(sig.param_patterns), 1))
                signals.append(f"params:{','.join(param_hits)}")
                
            # Recency boost
            if name in self.recency_buffer[-5:]:
                score += self.config.recency_weight
                signals.append("recent")
                
            if score > 0:
                candidates.append(RouteCandidate(
                    tool_name=name,
                    score=score,
                    match_signals=signals,
                ))
        
        # Sort descending, take top-k
        candidates.sort(key=lambda c: c.score, reverse=True)
        return candidates[:self.config.top_k]
    
    def record_selection(self, request: dict[str, Any], selected_tool: str) -> None:
        """Record actual tool selection for calibration."""
        self.recency_buffer.append(selected_tool)
        if len(self.recency_buffer) > 50:
            self.recency_buffer = self.recency_buffer[-50:]
            
        if self._mode == "dense":
            self.calibration_data.append({
                "request_text": self._extract_text_signal(request),
                "params": list(request.get("params", {}).keys()),
                "selected": selected_tool,
                "indexed_top_k": [c.tool_name for c in self.index(request)],
            })
    
    def calibration_accuracy(self) -> float:
        """
        What % of actual selections were in the indexer's top-k?
        This is the KL-divergence proxy — we want this > 95%.
        """
        if not self.calibration_data:
            return 0.0
        hits = sum(
            1 for d in self.calibration_data
            if d["selected"] in d["indexed_top_k"]
        )
        return hits / len(self.calibration_data)
    
    def should_switch_to_sparse(self) -> bool:
        """Switch to sparse mode when calibration accuracy > 95% over 100+ samples."""
        return (
            len(self.calibration_data) >= 100
            and self.calibration_accuracy() >= 0.95
        )
    
    # --- Private helpers ---
    
    def _extract_text_signal(self, request: dict[str, Any]) -> str:
        """Pull text signal from request for cheap matching."""
        parts = [
            str(request.get("method", "")),
            str(request.get("description", "")),
            json.dumps(request.get("params", {})),
        ]
        return " ".join(parts)
    
    def _detect_domain(self, text: str) -> str | None:
        """Cheap regex domain detection."""
        domain_patterns: dict[str, list[str]] = {
            "lighting": [r"\blight\b", r"\blamp\b", r"\bintensity\b", r"\bcolor\b.*\blight\b", r"\bkarma.*light\b"],
            "material": [r"\bmaterial\b", r"\bshader\b", r"\bmtlx\b", r"\bsurface\b", r"\btexture\b"],
            "render":   [r"\brender\b", r"\bkarma\b", r"\brop\b", r"\bimage\b.*\boutput\b"],
            "scene":    [r"\bnode\b", r"\bcreate\b", r"\bdelete\b", r"\btransform\b", r"\bgeometry\b"],
            "memory":   [r"\bmemory\b", r"\brecall\b", r"\bsave\b.*\bcontext\b", r"\bsession\b"],
        }
        text_lower = text.lower()
        for domain, patterns in domain_patterns.items():
            if any(re.search(p, text_lower) for p in patterns):
                return domain
        return None


# --- Tool Signature Registry ---

def build_signatures_from_registry(registry: dict[str, Any]) -> dict[str, ToolSignature]:
    """
    Auto-generate ToolSignatures from the existing tool registry.
    
    Reads tool names, descriptions, and parameter schemas to build
    lightweight fingerprints. Called once at server startup.
    """
    signatures: dict[str, ToolSignature] = {}
    
    for tool_name, tool_def in registry.items():
        description = tool_def.get("description", "")
        params = set(tool_def.get("inputSchema", {}).get("properties", {}).keys())
        
        # Extract keywords from description
        # Simple approach: take nouns and domain terms
        words = set(re.findall(r'\b[a-z]{3,}\b', description.lower()))
        stop_words = {"the", "and", "for", "with", "that", "this", "from", "will", "are"}
        keywords = frozenset(words - stop_words)
        
        # Infer domain from description
        domain = "scene"  # default
        domain_keywords = {
            "lighting": {"light", "lamp", "intensity", "illumination"},
            "material": {"material", "shader", "surface", "texture", "mtlx"},
            "render":   {"render", "karma", "image", "output", "rop"},
            "memory":   {"memory", "context", "session", "recall", "store"},
            "system":   {"ping", "status", "health", "version", "connection"},
        }
        for d, kw in domain_keywords.items():
            if keywords & kw:
                domain = d
                break
        
        # Infer cost tier
        cost_tier = 1  # default: read-only
        if any(w in description.lower() for w in ("create", "set", "modify", "delete", "write")):
            cost_tier = 2  # mutation
        if any(w in description.lower() for w in ("render", "cook", "execute")):
            cost_tier = 3  # heavy
            
        signatures[tool_name] = ToolSignature(
            name=tool_name,
            domain=domain,
            keywords=keywords,
            param_patterns=frozenset(params),
            cost_tier=cost_tier,
        )
    
    return signatures
```

```python
# In MCP server's handle_tool_call method:

async def handle_tool_call(self, request: dict) -> dict:
    # SPARSE: pre-filter
    candidates = self.sparse_router.index(request)
    candidate_names = {c.tool_name for c in candidates}
    
    # If indexer is confident (mode=sparse), only evaluate candidates
    if self.sparse_router._mode == "sparse" and candidates:
        tool = self._match_tool(request, restrict_to=candidate_names)
    else:
        # DENSE: evaluate all (calibration mode or low-confidence fallback)
        tool = self._match_tool(request, restrict_to=None)
    
    result = await self._execute_tool(tool, request)
    
    # Record for calibration
    self.sparse_router.record_selection(request, tool.name)
    
    return result
```

### Pattern 2: Persistent Reasoning Context

**Problem:** Autonomous render agent chains 5-15 tool calls. Artistic intent, parameter history, and evaluation criteria evaporate between calls.

**Solution:** ReasoningContext object that survives tool boundaries, compresses intelligently, and archives to SYNAPSE memory system.

#### File: `src/agent/reasoning_context.py`

```python
"""
Persistent Reasoning Context — DeepSeek thinking-in-tool-use pattern.

Maintains reasoning trace across multi-tool agent chains.
Integrates with SYNAPSE memory system for long-term archival.

Three protected categories (NEVER dropped during compression):
  1. Active decisions — what we decided and why
  2. Unresolved questions — what we still need to figure out
  3. Planned next steps — what we intend to do next
"""

from __future__ import annotations

import time
from dataclasses import dataclass, field
from enum import Enum
from typing import Any


class EntryCategory(Enum):
    """Categories for reasoning trace entries."""
    DECISION = "decision"           # Protected: active decisions
    QUESTION = "question"           # Protected: unresolved questions  
    PLAN = "plan"                   # Protected: planned next steps
    OBSERVATION = "observation"     # Compressible: tool results, findings
    ANALYSIS = "analysis"           # Compressible: reasoning about results
    CONTEXT = "context"             # Compressible: background info


PROTECTED_CATEGORIES = frozenset({
    EntryCategory.DECISION,
    EntryCategory.QUESTION,
    EntryCategory.PLAN,
})


@dataclass
class ReasoningEntry:
    """Single entry in the reasoning trace."""
    category: EntryCategory
    content: str
    timestamp: float = field(default_factory=time.time)
    tool_call: str | None = None       # which tool produced this
    confidence: float = 1.0            # 0.0-1.0, affects compression priority
    compressed: bool = False           # has this been compressed already?
    
    @property
    def is_protected(self) -> bool:
        return self.category in PROTECTED_CATEGORIES


@dataclass
class ReasoningContext:
    """
    Persistent reasoning trace across multi-tool agent chains.
    
    Usage:
        ctx = ReasoningContext(intent="Create warm studio lighting")
        ctx.add_decision("Using 3-point lighting setup for portrait feel")
        ctx.add_plan("Step 1: Key light at 45° camera-left")
        
        result = await call_tool("create_light", params)
        ctx.add_observation(f"Key light created: {result}", tool="create_light")
        
        ctx.add_plan("Step 2: Fill light at 30° camera-right, 0.3x key intensity")
        # ... chain continues with full context
    """
    
    intent: str                                    # artistic/technical intent (never compressed)
    entries: list[ReasoningEntry] = field(default_factory=list)
    tool_chain: list[str] = field(default_factory=list)  # ordered tool call history
    max_entries: int = 100                         # trigger compression above this
    compression_target: int = 50                   # compress down to this many entries
    
    # --- Public API: Add entries ---
    
    def add_decision(self, content: str, confidence: float = 1.0) -> None:
        self._add(EntryCategory.DECISION, content, confidence=confidence)
        
    def add_question(self, content: str) -> None:
        self._add(EntryCategory.QUESTION, content)
        
    def add_plan(self, content: str) -> None:
        self._add(EntryCategory.PLAN, content)
        
    def add_observation(self, content: str, tool: str | None = None, confidence: float = 0.8) -> None:
        self._add(EntryCategory.OBSERVATION, content, tool=tool, confidence=confidence)
        
    def add_analysis(self, content: str, confidence: float = 0.9) -> None:
        self._add(EntryCategory.ANALYSIS, content, confidence=confidence)
        
    def add_context(self, content: str) -> None:
        self._add(EntryCategory.CONTEXT, content, confidence=0.5)
    
    def record_tool_call(self, tool_name: str) -> None:
        """Record a tool invocation in the chain."""
        self.tool_chain.append(tool_name)
        
    # --- Public API: Query ---
    
    @property
    def active_decisions(self) -> list[ReasoningEntry]:
        return [e for e in self.entries if e.category == EntryCategory.DECISION]
    
    @property
    def open_questions(self) -> list[ReasoningEntry]:
        return [e for e in self.entries if e.category == EntryCategory.QUESTION]
    
    @property
    def next_steps(self) -> list[ReasoningEntry]:
        return [e for e in self.entries if e.category == EntryCategory.PLAN]
    
    def summarize(self, max_tokens: int = 500) -> str:
        """
        Generate a compressed summary for inclusion in tool call context.
        Protected categories always included in full.
        Compressible categories summarized.
        """
        parts = [f"INTENT: {self.intent}"]
        
        if self.active_decisions:
            parts.append("DECISIONS:")
            for e in self.active_decisions:
                parts.append(f"  • {e.content}")
                
        if self.open_questions:
            parts.append("OPEN QUESTIONS:")
            for e in self.open_questions:
                parts.append(f"  ? {e.content}")
                
        if self.next_steps:
            parts.append("NEXT STEPS:")
            for e in self.next_steps:
                parts.append(f"  → {e.content}")
        
        # Add recent observations (last 5)
        recent_obs = [e for e in self.entries if e.category == EntryCategory.OBSERVATION][-5:]
        if recent_obs:
            parts.append("RECENT OBSERVATIONS:")
            for e in recent_obs:
                tool_tag = f"[{e.tool_call}] " if e.tool_call else ""
                parts.append(f"  {tool_tag}{e.content}")
        
        parts.append(f"TOOL CHAIN: {' → '.join(self.tool_chain[-10:])}")
        
        return "\n".join(parts)
    
    def to_memory_record(self) -> dict[str, Any]:
        """
        Export reasoning context for SYNAPSE memory system archival.
        Integrates with markdown → USD memory evolution.
        """
        return {
            "type": "reasoning_chain",
            "intent": self.intent,
            "decisions": [e.content for e in self.active_decisions],
            "open_questions": [e.content for e in self.open_questions],
            "tool_chain": self.tool_chain,
            "entry_count": len(self.entries),
            "timestamp": time.time(),
        }
    
    # --- Compression ---
    
    def compress_if_needed(self) -> bool:
        """
        Compress trace if above max_entries threshold.
        Returns True if compression occurred.
        
        Strategy:
          1. Never touch protected categories (decisions, questions, plans)
          2. Merge consecutive observations from same tool
          3. Drop low-confidence entries first
          4. Summarize older analysis entries
        """
        if len(self.entries) <= self.max_entries:
            return False
            
        protected = [e for e in self.entries if e.is_protected]
        compressible = [e for e in self.entries if not e.is_protected]
        
        # Sort compressible by (already_compressed ASC, confidence ASC, timestamp ASC)
        # = compress already-compressed first, then low confidence, then oldest
        compressible.sort(key=lambda e: (e.compressed, e.confidence, e.timestamp))
        
        # Keep enough compressible entries to hit target
        keep_count = max(0, self.compression_target - len(protected))
        kept = compressible[-keep_count:] if keep_count > 0 else []
        
        # Mark surviving compressible as compressed
        for e in kept:
            e.compressed = True
        
        self.entries = protected + kept
        # Re-sort by timestamp
        self.entries.sort(key=lambda e: e.timestamp)
        
        return True
    
    # --- Private ---
    
    def _add(
        self,
        category: EntryCategory,
        content: str,
        tool: str | None = None,
        confidence: float = 1.0,
    ) -> None:
        self.entries.append(ReasoningEntry(
            category=category,
            content=content,
            tool_call=tool,
            confidence=confidence,
        ))
        self.compress_if_needed()


class ReasoningContextManager:
    """
    Manages multiple reasoning contexts for concurrent agent chains.
    Each chain gets its own context, keyed by chain_id.
    """
    
    def __init__(self) -> None:
        self.contexts: dict[str, ReasoningContext] = {}
        
    def create(self, chain_id: str, intent: str) -> ReasoningContext:
        ctx = ReasoningContext(intent=intent)
        self.contexts[chain_id] = ctx
        return ctx
        
    def get(self, chain_id: str) -> ReasoningContext | None:
        return self.contexts.get(chain_id)
        
    def archive(self, chain_id: str) -> dict[str, Any] | None:
        """Archive context to memory system and remove from active."""
        ctx = self.contexts.pop(chain_id, None)
        if ctx:
            return ctx.to_memory_record()
        return None
```

```python
            ctx.add_plan(evaluation.revised_plan)

    await self.memory_system.store(memory_record)
```

### Pattern 3: Specialist Domain Modes

**Problem:** Single system prompt handles all domains. Lighting requests get generic responses instead of lighting-expert responses.

**Solution:** Domain-specific specialist configs with tailored system prompts, parameter vocabularies, and verifiable reward functions.

#### File: `src/agent/specialist_modes.py`

```python
"""
Specialist Domain Modes — DeepSeek specialist distillation pattern.

Each domain gets:
  1. Tailored system prompt (domain vocabulary, conventions)
  2. Verifiable reward function (deterministic success criteria)
  3. Parameter vocabulary (H21-specific naming)
  4. Evaluation rubric (domain-specific quality signals)
  
Routing: Sparse router (Pattern 1) identifies domain → specialist config loaded.
"""
```

### Pattern 4: Synthetic Task Generation for Agent Testing

**Problem:** Manual test writing can't cover the combinatorial space of scene setups, lighting configurations, material assignments, and render settings that the autonomous agent will encounter.

**Solution:** Programmatic task environment generator that creates diverse, structured test scenarios.

#### File: `src/agent/task_synthesizer.py`

```python
"""
Synthetic Task Synthesizer — DeepSeek agentic task synthesis pattern.

Generates diverse test environments for autonomous render agent validation.
Prioritizes DIVERSITY over volume: 100 genuinely different task structures
beats 1000 variations of the same task.

Axes of variation:
  - Scene complexity (1 object → full environment)
  - Lighting setup (single → multi-light → HDRI → mixed)
  - Material complexity (default → textured → layered)
  - Render settings (preview → production)
  - Constraint types (time budget, quality floor, VRAM ceiling)
  - Failure modes (missing assets, invalid params, render crash)
"""

from __future__ import annotations

import itertools
import random
from dataclasses import dataclass, field
from enum import Enum
from typing import Any


class Complexity(Enum):
    MINIMAL = 1      # single object, single light
    SIMPLE = 2       # 2-3 objects, basic lighting
    MODERATE = 3     # scene with multiple elements
    COMPLEX = 4      # full environment
    PRODUCTION = 5   # production-level scene


class ConstraintType(Enum):
    TIME_BUDGET = "time"           # must complete within N seconds
    QUALITY_FLOOR = "quality"      # render must meet quality threshold
    VRAM_CEILING = "vram"          # must fit in 24GB
    SAMPLE_BUDGET = "samples"      # max render samples
    RESOLUTION = "resolution"      # specific output resolution required


class FailureMode(Enum):
    NONE = "none"                  # happy path
    MISSING_ASSET = "missing"      # referenced asset doesn't exist
    INVALID_PARAM = "invalid"      # parameter value out of range
    RENDER_TIMEOUT = "timeout"     # render exceeds time budget
    VRAM_OVERFLOW = "vram"         # scene exceeds GPU memory
    AMBIGUOUS_INTENT = "ambiguous" # vague or contradictory user request


@dataclass
class TaskEnvironment:
    """A single synthetic test environment."""
    task_id: str
    description: str
    scene_complexity: Complexity
    lighting_type: str             # "single" | "three_point" | "hdri" | "mixed" | "practical"
    material_type: str             # "default" | "textured" | "layered" | "emissive"
    render_target: str             # "preview" | "lookdev" | "production"
    constraints: list[dict[str, Any]]
    failure_mode: FailureMode
    expected_tool_chain: list[str] # expected sequence of tool calls
    success_criteria: list[str]    # verifiable conditions for pass/fail
    
    
@dataclass
class TaskSynthesizer:
    """
    Generates diverse task environments for agent testing.
    
    Usage:
        synth = TaskSynthesizer(seed=42)
        envs = synth.generate(n=200, diversity_threshold=0.7)
        
        for env in envs:
            result = agent.execute(env)
            assert env.evaluate(result)
    """
    
    seed: int = 42
    
    # --- Generation axes ---
    
    LIGHTING_TYPES = ["single", "three_point", "hdri", "mixed", "practical"]
    MATERIAL_TYPES = ["default", "textured", "layered", "emissive"]
    RENDER_TARGETS = ["preview", "lookdev", "production"]
    
    TASK_TEMPLATES: list[dict[str, Any]] = field(default_factory=lambda: [
        {
            "template": "Create {lighting_type} lighting for a {scene_desc}",
            "domain": "lighting",
            "tool_chain_pattern": ["create_light", "set_params", "render_preview"],
        },
        {
            "template": "Apply {material_type} material to {object_desc} and render",
            "domain": "material",
            "tool_chain_pattern": ["create_material", "assign_material", "render_preview"],
        },
        {
            "template": "Set up {scene_desc} with {lighting_type} lighting and {material_type} materials",
            "domain": "scene",
            "tool_chain_pattern": ["create_geo", "create_light", "create_material", "assign_material", "render_preview"],
        },
        {
            "template": "Render {scene_desc} at {render_target} quality within {time_budget}s",
            "domain": "render",
            "tool_chain_pattern": ["configure_render", "render", "evaluate_quality"],
        },
        {
            "template": "Iterate on {scene_desc} lighting: {intent}",
            "domain": "lighting",
            "tool_chain_pattern": ["query_memory", "adjust_light", "render_preview", "evaluate", "adjust_light", "render_preview"],
        },
        {
            "template": "Debug render issue: {failure_desc}",
            "domain": "render",
            "tool_chain_pattern": ["inspect_scene", "diagnose", "fix", "render_preview", "verify"],
        },
    ])
    
    SCENE_DESCRIPTIONS = [
        "hero product on white background",
        "interior room with window light",
        "exterior landscape at golden hour",
        "character portrait with dramatic lighting",
        "architectural visualization of lobby",
        "abstract geometric composition",
        "food photography setup",
        "vehicle in studio environment",
        "jewelry close-up with caustics",
        "foggy forest with volumetrics",
    ]
    
    ARTISTIC_INTENTS = [
        "make it feel warm and inviting",
        "create dramatic contrast",
        "soft and ethereal mood",
        "hyper-realistic product shot",
        "cinematic film look",
        "clean and minimal",
        "moody and mysterious",
        "bright and energetic",
    ]

    def generate(self, n: int = 200, diversity_threshold: float = 0.7) -> list[TaskEnvironment]:
        """
        Generate n diverse task environments.
        
        diversity_threshold: minimum pairwise diversity score (0.0-1.0).
        Rejects generated tasks that are too similar to existing ones.
        """
        rng = random.Random(self.seed)
        environments: list[TaskEnvironment] = []
        attempts = 0
        max_attempts = n * 5  # prevent infinite loop
        
        while len(environments) < n and attempts < max_attempts:
            attempts += 1
            env = self._generate_single(rng, len(environments))
            
            if self._is_diverse_enough(env, environments, diversity_threshold):
                environments.append(env)
        
        return environments
    
    def _generate_single(self, rng: random.Random, idx: int) -> TaskEnvironment:
        """Generate a single task environment."""
        template = rng.choice(self.TASK_TEMPLATES)
        complexity = rng.choice(list(Complexity))
        lighting = rng.choice(self.LIGHTING_TYPES)
        material = rng.choice(self.MATERIAL_TYPES)
        render_target = rng.choice(self.RENDER_TARGETS)
        scene_desc = rng.choice(self.SCENE_DESCRIPTIONS)
        intent = rng.choice(self.ARTISTIC_INTENTS)
        
        # Generate constraints based on complexity
        constraints = self._generate_constraints(rng, complexity, render_target)
        
        # Select failure mode (20% of tasks include failure scenarios)
        failure_mode = FailureMode.NONE
        if rng.random() < 0.2:
            failure_mode = rng.choice([
                FailureMode.MISSING_ASSET,
                FailureMode.INVALID_PARAM,
                FailureMode.RENDER_TIMEOUT,
                FailureMode.AMBIGUOUS_INTENT,
            ])
        
        description = template["template"].format(
            lighting_type=lighting,
            material_type=material,
            scene_desc=scene_desc,
            render_target=render_target,
            object_desc=scene_desc.split()[0],
            time_budget=rng.choice([30, 60, 120, 300]),
            intent=intent,
            failure_desc=f"{failure_mode.value} during {template['domain']} operation",
        )
        
        return TaskEnvironment(
            task_id=f"synth_{idx:04d}",
            description=description,
            scene_complexity=complexity,
            lighting_type=lighting,
            material_type=material,
            render_target=render_target,
            constraints=constraints,
            failure_mode=failure_mode,
            expected_tool_chain=template["tool_chain_pattern"],
            success_criteria=self._generate_success_criteria(
                template["domain"], complexity, failure_mode
            ),
        )
    
    def _generate_constraints(
        self, rng: random.Random, complexity: Complexity, render_target: str
    ) -> list[dict[str, Any]]:
        """Generate realistic constraints for a task."""
        constraints: list[dict[str, Any]] = []
        
        # Time budget (always present)
        time_budgets = {
            Complexity.MINIMAL: 30,
            Complexity.SIMPLE: 60,
            Complexity.MODERATE: 120,
            Complexity.COMPLEX: 300,
            Complexity.PRODUCTION: 600,
        }
        constraints.append({
            "type": ConstraintType.TIME_BUDGET.value,
            "value": time_budgets[complexity],
        })
        
        # VRAM ceiling (always 24GB for RTX 4090)
        constraints.append({
            "type": ConstraintType.VRAM_CEILING.value,
            "value": 24_000,  # MB
        })
        
        # Quality floor for production renders
        if render_target == "production":
            constraints.append({
                "type": ConstraintType.QUALITY_FLOOR.value,
                "value": 0.95,  # convergence threshold
            })
        
        # Resolution
        resolutions = {
            "preview": (960, 540),
            "lookdev": (1920, 1080),
            "production": (3840, 2160),
        }
        constraints.append({
            "type": ConstraintType.RESOLUTION.value,
            "value": resolutions[render_target],
        })
        
        return constraints
    
    def _generate_success_criteria(
        self, domain: str, complexity: Complexity, failure_mode: FailureMode
    ) -> list[str]:
        """Generate verifiable success criteria."""
        criteria = ["Agent completed without crash"]
        
        if failure_mode != FailureMode.NONE:
            criteria.append(f"Agent detected and handled {failure_mode.value} failure")
            criteria.append("Agent reported failure to user with actionable guidance")
        else:
            criteria.append("All tool calls executed successfully")
            criteria.append("Final render produced valid image output")
            
        domain_criteria = {
            "lighting": ["Light nodes created with valid parameters", "Intensity values physically plausible"],
            "material": ["Material binding resolved correctly", "Texture color spaces set appropriately"],
            "render": ["Render converged within sample budget", "Output file written successfully"],
            "scene": ["Scene hierarchy is valid USD", "No orphaned prims"],
        }
        criteria.extend(domain_criteria.get(domain, []))
        
        return criteria
    
    def _is_diverse_enough(
        self, candidate: TaskEnvironment, existing: list[TaskEnvironment], threshold: float
    ) -> bool:
        """Check if candidate is sufficiently different from existing environments."""
        if not existing:
            return True
            
        for env in existing:
            similarity = self._compute_similarity(candidate, env)
            if similarity > (1.0 - threshold):
                return False
        return True
    
    def _compute_similarity(self, a: TaskEnvironment, b: TaskEnvironment) -> float:
        """Compute similarity score between two environments (0.0-1.0)."""
        score = 0.0
        dimensions = 6
        
        if a.scene_complexity == b.scene_complexity:
            score += 1.0
        if a.lighting_type == b.lighting_type:
            score += 1.0
        if a.material_type == b.material_type:
            score += 1.0
        if a.render_target == b.render_target:
            score += 1.0
        if a.failure_mode == b.failure_mode:
            score += 1.0
        if a.expected_tool_chain == b.expected_tool_chain:
            score += 1.0
            
        return score / dimensions
```
