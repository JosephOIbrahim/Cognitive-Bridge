Capture screenshots at key moments — For a multimodal RAG, you could extract keyframes from the videos to pair visual context (node graphs, parameter settings, viewport screenshots) with the transcripts.
Supplement with lesson descriptions — Scrape whatever text descriptions exist on each lesson page to add metadata and context.
Chunk and embed — Once you have transcripts, chunk them by topic/timestamp, generate embeddings, and store them in a vector database (like Pinecone, Chroma, Weaviate, etc.).
Build the retrieval pipeline — Use an LLM (like Claude or GPT-4) to answer Houdini-related questions by retrieving relevant transcript chunks.
