## ROOT COMPOSITION FILE

`cognitive_substrate_root.usda` controls sublayer ordering. **Later sublayers have stronger opinions** (USD LIVRPS rule). Research grafts override/extend the core.

```usda
#usda 1.0
(
    doc = "Cognitive Substrate Root — USD Source of Truth for Claude Code"
    subLayers = [
        # GRAFTS (stronger opinion — listed first in USD sublayer order)
        @./grafts/graft_deepseek_v32.usda@,
        # @./grafts/graft_infmem.usda@,        ← uncomment when ready
        # @./grafts/graft_alphaproof.usda@,     ← uncomment when ready
        
        # CORE (weakest opinion — base layer)
        @./core_substrate_v7.usda@
    ]
)
```

To disable a graft: comment out its sublayer line. To re-order priority: move lines up (stronger) or down (weaker).

## CONVERTER SPEC

`converter.py` requirements:

1. **Input:** `cognitive_substrate_root.usda` (reads sublayer composition)
2. **Process:** 
   - Parse each `.usda` file in sublayer order
   - Extract content from string attributes and doc strings
   - Apply `over` prims as modifications to existing sections
   - Apply `def` prims as new sections
   - Respect variant selections if present
3. **Output:** `~/.claude/CLAUDE.md` with header comment:
   ```
   <!-- AUTO-GENERATED by cognitive_substrate/converter.py -->
   <!-- Source of truth: cognitive_substrate/cognitive_substrate_root.usda -->
   <!-- DO NOT EDIT. Modify .usda files and rerun converter. -->
   <!-- Generated: {timestamp} -->
   ```
4. **Append** `CLAUDE_manual.md` contents at the end (if file exists)
5. **Run modes:**
   - `python converter.py` — one-shot compile
   - `python converter.py --watch` — file watcher, recompile on .usda change
   - `python converter.py --dry-run` — print output without writing
   - `python converter.py --diff` — show what would change vs current CLAUDE.md

**Converter approach for USDA → Markdown:**

Since Claude Code doesn't have a USD runtime, the converter should work as a structured text processor. Each `.usda` file uses a convention:

```usda
def "SectionName" (
    doc = "## Section Title"
)
{
    # markdown_content is the actual CLAUDE.md content for this section
    string markdown_content = '''
    The actual markdown that goes into CLAUDE.md lives here.
    This is the content Claude Code will read.
    '''
    
    # metadata for the converter
    int priority = 50           # 0-100, higher = earlier in output
    bool enabled = true         # false = skip this section
    string inject_after = ""    # insert after this section name (empty = use priority)
    string replaces = ""        # if set, replaces this section name from core
}
```

`over` prims modify existing sections:
```usda
over "ExistingSection" {
    # Appends to or replaces content in the core's ExistingSection
    string markdown_append = '''
    Additional content added by this graft.
    '''
    # OR
    string markdown_replace = '''
    Completely replaces the core section content.
    '''
}
```

## GRAFT TEMPLATE

```usda

(
    doc = """Research Graft: [PAPER NAME]
    Source: [arxiv link]

    Author: Joe
    
    Patterns transferred:
    - [Pattern 1 name]
    - [Pattern 2 name]
    
    Integration points:
    - [What this modifies in the core substrate]

def "Preamble" (
    doc = "Graft metadata"
)
{
    string paper_title = "[Paper Title]"
    string arxiv_id = "[arxiv ID]"
    string date_grafted = "[YYYY-MM-DD]"
    string[] patterns = ["pattern_1", "pattern_2"]
    string[] integration_targets = ["RoutingCascade", "MomentumEngine"]
}

# --- NEW SECTIONS (def = additive) ---

def "NewCapability" (
    doc = "## New Section Title"
)
{
    string markdown_content = '''
    New content added by this research graft.
    '''
    int priority = 60
    bool enabled = true
}

# --- MODIFICATIONS TO EXISTING SECTIONS (over = modify) ---

over "ExistingCoreSectionName" {
    string markdown_append = '''
    
    ### [Graft Name] Enhancement
    Additional content from this research graft.
    '''
}
```
