Also add: when a node starts executing, auto-pan the canvas to center on that node if it's off-screen. Use this pattern:

const node = app.graph.getNodeById(nodeId);
if (node) {
  const canvas = app.canvas;
  const [nx, ny] = [node.pos[0] + node.size[0]/2, node.pos[1] + node.size[1]/2];
  const visible = canvas.visible_area;
  // Only pan if node is outside visible area
  if (nx < visible[0] || nx > visible[0]+visible[2] || ny < visible[1] || ny > visible[1]+visible[3]) {
    canvas.centerOnNode(node);
  }
}

FILE 3: ui/web/js/sidebar.js (continued)

Listen for the node_executing/node_executed events from node_fx. When a node starts executing, add a small status line to the chat area:

document.addEventListener("superduper:node_executing", (e) => {
  // Only show if we have an active progress panel
  if (!progressPanel) return;
  // Update progress panel with current node name
  updateProgress(progressPanel, { currentNode: e.detail.nodeName });
});

This closes the loop: chat actions highlight nodes, node execution updates the chat. The two panels stay in sync.
