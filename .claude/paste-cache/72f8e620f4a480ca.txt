### Step 4: Extend the converter

Add a new output direction or format flag:
```bash
# Existing
python converter.py --direction usd-to-md              # Claude Code CLAUDE.md

# New

python converter.py --direction usd-to-md --format both      # Generate both
```

Or a simpler approach — a separate output flag:
```bash

```
