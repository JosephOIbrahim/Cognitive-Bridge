## BATCH 6 — GA4 INTEGRATION

Install Google Analytics using the Next.js Script component. The user will provide the GA4 Measurement ID (format: `G-XXXXXXXXXX`).

### Create `components/Analytics.tsx`
```typescript
'use client';
import Script from 'next/script';

export function Analytics() {
  const GA_ID = process.env.NEXT_PUBLIC_GA_ID;
  if (!GA_ID) return null;
  
  return (
    <>
      <Script src={`https://www.googletagmanager.com/gtag/js?id=${GA_ID}`} strategy="afterInteractive" />
      <Script id="ga4" strategy="afterInteractive">
        {`window.dataLayer=window.dataLayer||[];function gtag(){dataLayer.push(arguments)}gtag('js',new Date());gtag('config','${GA_ID}');`}
      </Script>
    </>
  );
}
```

### Add to root layout
Import and render `<Analytics />` inside the `<body>` of `app/layout.tsx`.

### Set environment variable
In Vercel dashboard → Project Settings → Environment Variables:
- Key: `NEXT_PUBLIC_GA_ID`
- Value: `G-XXXXXXXXXX` (to be provided)

**Verification:** After deploying with the env var set, check the browser Network tab for a request to `google-analytics.com` or `googletagmanager.com`.
